Perform mathematical calculations including addition, subtraction, multiplication, division, and more.

<
Relational Operators

Compare values and make decisions based on relationships between data.

< 5 < 5 False
> 10 > 7 True
<= 3 <= 5 True
==
Equality Operators

Compare equality between data.

== True == False False
!= True != False True
&&
Logical Operators

Perform logical operations on data.

and True and False False
or True or False True
not not True False
&
Bitwise Operators

Perform bitwise operations on data.

& True & False False
| True | False True
^ True ^ False True
~ True ~ False True
<< True << False True
>> True >> False True
>>
Shift Operators

Shift bits of a number to the left or right.

<< 10 << 2 40
>> 10 >> 2 2
=
Assignment Operators

Assign and modify variable values efficiently with compound operators.

= x = 10 10
+= x += 5 15
*= x *= 2 30
?:
Ternary Operator

Use the ternary operator to perform a comparison and return a value based on the result.

? if "equal" if 10 == 10 else "not equal" equal
: if "not equal" if 10 != 20 else "equal" not equal
is/in
Identity Operator and Membership Operator

Use the identity operator to compare the memory addresses of two objects and return a boolean result.

is x = 10 y = 10 x is y True
in x = [1, 2, 3] 2 in x True

Operator Precedence

Use the operator precedence to determine the order of operations in an expression.

()**+ x = (10+10)**2-1 x 209
+ x = 10**2+3+(10-1) x 112
