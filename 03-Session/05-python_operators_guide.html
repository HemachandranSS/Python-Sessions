🐍 PYTHON OPERATORS

Operators are symbols that perform specific operations on values and variables. Python provides six main categories of operators to manipulate data and control program flow.

Floor Division (//): Returns the largest integer less than or equal to the result.

Modulus (%): Returns the remainder after division.

Exponentiation (**): Raises the first number to the power of the second.

AND: Returns True only if both operands are True.

OR: Returns True if at least one operand is True.

NOT: Returns the opposite Boolean value.

Perform operations on binary representations of numbers.

AND (&): Sets bit to 1 if both bits are 1.

OR (|): Sets bit to 1 if any bit is 1.

XOR (^): Sets bit to 1 if bits are different.

NOT (~): Inverts all bits.

Left Shift (<<): Shifts bits left, multiplies by 2^n.

Right Shift (>>): Shifts bits right, divides by 2^n.

Compound Assignment: Combines operation with assignment.

Example: x += 5 is equivalent to x = x + 5

Available: +=, -=, *=, /=, //=, %=, **=, &=, |=, ^=, <<=, >>=

6. Special Operators
Identity and membership operators for advanced comparisons.

Identity (is): Checks if variables point to the same object.

Membership (in): Checks if value exists in a sequence.

Difference: 'is' checks object identity, '==' checks value equality.
