Arithmetic Operators

+
Addition
Adds two operands together
a = 10
b = 5
result = a + b # 15
+=
Add and Assign
Adds right operand to left operand and assigns result to left operand
x = 10
x += 5 # x = x + 5
print(x) # 15
-=
Subtract and Assign
Subtracts right operand from left operand and assigns result
x = 10
x -= 3 # x = x - 3
print(x) # 7
*=
Multiply and Assign
Multiplies left operand by right operand and assigns result
x = 5
x *= 4 # x = x * 4
print(x) # 20
/=
Divide and Assign
Divides left operand by right operand and assigns result
x = 20
x /= 4 # x = x / 4
print(x) # 5.0
%=
Modulus and Assign
Applies modulus operation and assigns result
x = 17
x %= 5 # x = x % 5
print(x) # 2
✨

Special Operators

is
Identity
Returns True if both operands refer to the same object
a = [1, 2, 3]
b = a
c = [1, 2, 3]
print(a is b) # True
print(a is c) # False
is not
Identity (Negative)
Returns True if operands refer to different objects
a = [1, 2]
b = [1, 2]
print(a is not b) # True
in
Membership
Returns True if value is found in sequence
fruits = ['apple', 'banana']
print('apple' in fruits) # True
print('orange' in fruits) # False
not in
Membership (Negative)
Returns True if value is not found in sequence
numbers = [1, 2, 3, 4]
print(5 not in numbers) # True
print(2 not in numbers) # False
? :
Ternary (Conditional)
Python's conditional expression (inline if-else)
age = 20
status = "adult" if age >= 18 else "minor"
print(status) # adult
:=
Walrus Operator
Assignment expression (Python 3.8+)
# Assign and use in one expression
if (n := len("Python")) > 5:
    print(f"Length is {n}") # Length is 6

Operator Precedence

Priority Operator Description Associativity
1 (Highest) () Parentheses Left to Right
2 ** Exponentiation Right to Left
3 +x, -x, ~x Unary plus, minus, bitwise NOT Left to Right
4 *, /, //, % Multiplication, Division, Floor division, Modulus Left to Right
5 +, - Addition, Subtraction Left to Right
6 <<, >> Bitwise shift operators Left to Right
7 & Bitwise AND Left to Right
8 ^ Bitwise XOR Left to Right
9 | Bitwise OR Left to Right
10 ==, !=, <, <=, >, >=, is, is not, in, not in Comparison operators Left to Right
11 not Logical NOT Left to Right
12 and Logical AND Left to Right
13 or Logical OR Left to Right
14 if-else Conditional expression Left to Right
15 (Lowest) =, +=, -=, *=, /=, //=, %=, **=, &=, |=, ^=, >>=, <<= Assignment operators Right to Left

-
Subtraction

a = 10
b = 3
result = a - b # 7
*
Multiplication
Multiplies two operands
a = 7
b = 3
result = a * b # 21

Division
Divides left operand by right operand (returns float)
a = 15
b = 4
result = a / b # 3.75

Floor Division
Returns floor of the division (integer result)
a = 15
b = 4
result = a // b # 3
%
Modulus
Returns remainder of division
a = 15
b = 4
result = a % b # 3
**
Exponentiation
Raises left operand to the power of right operand
a = 2
b = 3
result = a ** b # 8

Comparison Operators

==
Equal To
Returns True if both operands are equal
a = 5
b = 5
result = a == b # True
!=
Not Equal To
Returns True if operands are not equal
a = 5
b = 3
result = a != b # True
>
Greater Than
Returns True if left operand is greater than right
a = 8
b = 5
result = a > b # True
<
Less Than
Returns True if left operand is less than right
a = 3
b = 7
result = a < b # True
>=
Greater Than or Equal
Returns True if left operand is greater than or equal to right
a = 5
b = 5
result = a >= b # True
<=
Less Than or Equal
Returns True if left operand is less than or equal to right
a = 4
b = 7
result = a <= b # True
🧠

Logical Operators

and
Logical AND
Returns True if both operands are True
a = True
b = False
result = a and b # False
or
Logical OR
Returns True if at least one operand is True
a = True
b = False
result = a or b # True
not
Logical NOT
Returns True if operand is False, and vice versa
a = True
result = not a # False
🔢

Bitwise Operators

&
Bitwise AND
Performs bitwise AND operation
a = 12 # 1100
b = 10 # 1010
result = a & b # 8 (1000)
|
Bitwise OR
Performs bitwise OR operation
a = 12 # 1100
b = 10 # 1010
result = a | b # 14 (1110)
^
Bitwise XOR
Performs bitwise XOR operation
a = 12 # 1100
b = 10 # 1010
result = a ^ b # 6 (0110)
~
Bitwise NOT
Performs bitwise NOT operation (complement)
a = 12
result = ~a # -13
<<
Left Shift
Shifts bits to the left
a = 5 # 101
result = a << 2 # 20 (10100)
>>
Right Shift
Shifts bits to the right
a = 20 # 10100
result = a >> 2 # 5 (101)
📝

Assignment Operators

=
Assignment
Assigns value to variable
x = 10
print(x) # 10
