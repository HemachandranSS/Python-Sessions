Ternary Operator

The ternary operator (also called conditional operator) is a concise way to write simple if-else statements in a single line.

x = firstValue if condition else secondValue

Pro Tip: While ternary operators are great for simple conditions, use traditional if/elif/else statements for complex logic to maintain code readability. Ternary is best for short, simple conditional assignments.
