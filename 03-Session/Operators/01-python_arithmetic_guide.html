🐍 Python Arithmetic Operators

Master the fundamental building blocks of Python mathematics

+
Addition
Adds two numbers or concatenates strings
10 + 5 = 15
"Hello" + " World" = "Hello World"
-
Subtraction
Subtracts the second number from the first
10 - 5 = 5
3.5 - 1.2 = 2.3
*
Multiplication
Multiplies two numbers or repeats strings
10 * 5 = 50
"Hi" * 3 = "HiHiHi"
/
Division
Divides numbers (always returns float)
10 / 3 = 3.333...
9 / 3 = 3.0
//
Floor Division
Divides and rounds down to nearest integer
10 // 3 = 3
10.5 // 2 = 5.0
%
Modulo
Returns the remainder after division
10 % 3 = 1
15 % 4 = 3
**
Exponent/Power
Raises first number to the power of second
2 ** 3 = 8
5 ** 2 = 25

🔍 Important Notes & Observations

Division Operator (/): Always performs floating-point arithmetic and returns a float value, even when dividing integers that result in whole numbers.
10 / 2 = 5.0 # Note: result is float, not int
Floor Division (//): Can perform both integer and floating-point arithmetic. If both operands are integers, result is integer. If at least one operand is float, result is float.
10 // 3 = 3 # int result
10.0 // 3 = 3.0 # float result
Zero Division Error: Division by zero (/) and modulo by zero (%) always raise ZeroDivisionError.
