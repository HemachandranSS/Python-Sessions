Special Operators

Python provides two special categories of operators for advanced comparisons and membership testing.

Identity Operators

Identity Operators

Identity operators compare the memory addresses of two objects to check if they are the same object in memory, not just equal in value.

is
Returns True if both variables point to the same object
is not
Returns True if variables point to different objects

Important Note
Use is for identity (address) comparison. Use == for content (value) comparison. Small integers and strings are often interned by Python for optimization.

Membership Operators

Membership operators test whether a value exists in a collection (string, list, tuple, set, or dictionary).

in
Returns True if item is present in the collection
not in
Returns True if item is not present in the collection

Use Cases
Membership operators are extremely useful for quick checks in conditionals and loops. They work with strings, lists, tuples, sets, and dictionaries (checking keys). For large collections, sets provide O(1) lookup time compared to lists' O(n).
