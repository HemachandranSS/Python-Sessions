🐍 Python Relational Operators

Interactive Guide to Comparison Operations

📊 The Four Main Relational Operators

>

Greater Than

>=

Greater Than or Equal

<

Less Than

<=

Less Than or Equal

🔢 Integer Comparison Examples

a = 10
b = 20
print("a > b is ", a > b)
print("a >= b is ", a >= b)
print("a < b is ", a < b)
print("a <= b is ", a <= b)
a > b is False
a >= b is False
a < b is True
a <= b is True

🔤 String Comparison Examples

🎯 Key Point: String comparisons work lexicographically (dictionary order)!

a = "durga"
b = "durga"
print("a > b is ", a > b)
print("a >= b is ", a >= b)
print("a < b is ", a < b)
print("a <= b is ", a <= b)
a > b is False
a >= b is True
a < b is False
a <= b is True

🔗 Operator Chaining Magic

✨ Python's Special Feature: Chain Multiple Comparisons!

Unlike many languages, Python allows you to chain relational operators naturally:

print(10 < 20) # True
print(10 < 20 < 30) # True
print(10 < 20 < 30 < 40) # True
print(10 < 20 < 30 < 40 > 50) # False

❌ Type Compatibility Errors

⚠️ When Comparisons Go Wrong

Python won't let you compare incompatible types:

print(10 > 'durga') # ❌ TypeError!

🛡️ Error Message: TypeError: '>' not supported between instances of 'int' and 'str'

✅ But these work fine:

print(True > True) # False
print(True >= True) # True
print(10 > True) # True (True = 1)
print(False > True) # False (False = 0)

🧠 Key Takeaways

🎯 Important Points:

  • 1. Relational operators return Boolean values (True/False)
  • 2. They work with numbers, strings, and other comparable types
  • 3. String comparison is lexicographic (alphabetical)
  • 4. Chaining operators creates elegant, readable conditions
  • 5. Comparing incompatible types raises TypeError
