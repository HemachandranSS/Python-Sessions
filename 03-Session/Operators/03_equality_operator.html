Equality Operators: == and !=

Learn how equality and inequality operators work in programming

These operators compare values for equality (==) or inequality (!=). They return True if the comparison holds, and False otherwise. They can be used with any types, even incompatible ones.

Code Examples

Basic Comparisons:

>>> 10 == 20
Result: False (10 is not equal to 20)
>>> 10 != 20
Result: True (10 is not equal to 20)

Comparing with Boolean values:

>>> 10 == True
Result: False (True has an integer value of 1, and 10 ≠ 1)
>>> False == False
Result: True (False is equal to False)

String comparisons:

>>> "hema" == "hema"
Result: True (Both strings are identical)

Incompatible type comparison:

>>> 10 == "hema"
Result: False (Integer cannot be equal to a string)

Chaining Concept

The chaining concept is applicable for equality operators. If at least one comparison returns False then the result is False. Otherwise, if all comparisons are True, the result is True.

>>> 10 == 20 == 30 == 40
Result: False

Explanation: 10 == 20 is False, so the entire expression is False.

>>> 10 == 10 == 10 == 10
Result: True

Explanation: All comparisons (10 == 10) are True, so the entire expression is True.

Key Points to Remember

  • Equality operators can compare values of any type, even incompatible ones
  • When comparing different types (e.g., number and string), the result is usually False
  • Boolean values True and False have integer equivalents (1 and 0 respectively)
  • Chaining multiple comparisons works as a logical AND of all individual comparisons
  • In the examples above, "hema" is used instead of "durga" as requested
