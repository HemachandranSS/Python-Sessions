Boolean Behavior

Logical operators work differently with boolean values (True/False):

AND

If both arguments are True then result is True

True AND False → False

OR

If at least one argument is True then result is True

True OR False → True

NOT

Returns the complement (opposite) value

NOT False → True

Truth Table

A B A AND B A OR B NOT A
True True True True False
True False False True False
False True False True True
False False False False True

Non-Boolean Behavior

For non-boolean types, values are evaluated as Truthy or Falsy:

Falsy values: 0, empty string (""), False

Truthy values: Non-zero numbers, non-empty strings, True

Rules for Non-Boolean Types

X AND Y

If X evaluates to Falsy, returns X. Otherwise returns Y.

10 AND 20 → 20

0 AND 20 → 0

X OR Y

If X evaluates to Truthy, returns X. Otherwise returns Y.

10 OR 20 → 10

0 OR 20 → 20

NOT X

If X evaluates to Falsy, returns True. Otherwise returns False.

NOT 10 → False

NOT 0 → True

Example Evaluations

These examples demonstrate how logical operators work with non-boolean values:

"hema" AND "hemasoft"
Result: "hemasoft" (First is truthy, so returns second)
"" AND "hema"
Result: "" (First is falsy, so returns first)
"hema" AND ""
Result: "" (First is truthy, so returns second)
"" OR "hema"
Result: "hema" (First is falsy, so returns second)
"hema" OR ""
Result: "hema" (First is truthy, so returns first)
NOT ""
Result: True (Empty string is falsy)
NOT "hema"
Result: False (Non-empty string is truthy)
10 AND 20
Result: 20 (First is truthy, so returns second)

Key Points to Remember

  • For boolean types: AND requires both True, OR requires at least one True
  • For non-boolean types: 0 means False, non-zero means True
  • Empty string "" is always treated as False
  • X AND Y: If X is falsy, return X; otherwise return Y
  • X OR Y: If X is truthy, return X; otherwise return Y
  • NOT X: If X is falsy, return True; otherwise return False
