🐍 Python Escape Characters & Constants

Master the art of special characters and constant conventions in Python

🎯 Escape Characters

Escape characters allow you to include special characters in strings that would otherwise be impossible or cause syntax errors.

\n
New Line
Creates a line break in the string
\t
Horizontal Tab
Inserts a horizontal tab space
\r
Carriage Return
Returns cursor to beginning of line
\b
Backspace
Moves cursor one position back
\f
Form Feed
Page break in printed output
\v
Vertical Tab
Inserts vertical tab space
\'
Single Quote
Includes single quote in string
\"
Double Quote
Includes double quote in string
\\
Backslash
Includes literal backslash

📝 Basic Example

s = "durga\nsoftware" print(s)
durga software

🔖 Tab Example

s = "Name:\tJohn\nAge:\t25" print(s)
Name: John Age: 25

💬 Quote Example

s = "She said \"Hello!\"" print(s)
She said "Hello!"

🛤️ Path Example

path = "C:\\Users\\John" print(path)
C:\Users\John

📊 Constants in Python

Python doesn't have true constants, but follows naming conventions!

⚠️ Important Note

Python doesn't enforce constants like other languages. It's purely a naming convention to use UPPERCASE letters for values that shouldn't change. You can still modify them, but it's considered bad practice.

✅ Good Practice

PI = 3.14159 MAX_SIZE = 100 DATABASE_URL = "localhost:5432" API_KEY = "abc123xyz" # Use them (don't change) radius = 5 area = PI * radius ** 2

❌ Bad Practice

PI = 3.14159 print(PI) # 3.14159 # This works but is wrong! PI = 2.5 print(PI) # 2.5 # Breaks the convention

🏢 Real World Example

CONFIG_FILE = "settings.ini" MAX_RETRIES = 3 TIMEOUT_SECONDS = 30 ERROR_CODES = { 404: "Not Found", 500: "Server Error" }

🎓 Key Takeaways

🎯 Escape Characters

  • Use backslash (\) to escape special characters
  • Essential for strings with quotes, newlines, tabs
  • Common ones: \n, \t, \", \', \\
  • Makes strings more readable and functional

📏 Constants

  • Python has no true constants
  • Use UPPERCASE for constant values
  • It's a convention, not enforced
  • Consider using Enum for true constants
