Python Bytes Data Type

Interactive Tutorial & Visual Demonstration

🔍 What are Bytes?

The bytes data type in Python represents an immutable sequence of integers in the range 0-255 (one byte each). Think of it as a read-only array of byte values that's perfect for handling binary data, network protocols, and file operations.

🔒

Immutable

Once created, you cannot modify individual elements

📊

0-255 Range

Each element must be between 0 and 255 inclusive

⚡

Memory Efficient

Optimized for storing binary data

📝 Basic Syntax & Examples

# Creating bytes from a list
x = [10, 20, 30, 40]
b = bytes(x)
print(type(b)) <class 'bytes'>
print(b) b'\n\x14\x1e('
# Accessing elements
print(b[0]) 10
print(b[-1]) 40
# Iterating through bytes
for i in b:
print(i) # 10, 20, 30, 40

🔒 Immutability Demonstration

Why Bytes Objects are Immutable

Once a bytes object is created, you cannot modify its contents. This is a fundamental characteristic that ensures data integrity.

x = [10, 20, 30, 40]
b = bytes(x)
b[0] = 100 # Attempting to modify
TypeError: 'bytes' object does not support item assignment

💡 Advanced Features & Methods

Slicing

b = bytes([10,20,30,40])
print(b[1:3]) b'\x14\x1e'

Concatenation

b1 = bytes([10, 20])
b2 = bytes([30, 40])
result = b1 + b2

Length & Contains

b = bytes([10,20,30])
len(b) 3
20 in b True

🔄 Bytes vs Other Types

# From string (encoding required)
text = "Hello"
b = text.encode('utf-8') b'Hello'
# From bytearray (mutable counterpart)
ba = bytearray([10, 20, 30])
b = bytes(ba) b'\n\x14\x1e'
# To list
b = bytes([65, 66, 67])
list(b) [65, 66, 67]
