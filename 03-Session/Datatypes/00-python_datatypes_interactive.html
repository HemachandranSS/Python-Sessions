🏷️ Data Type 📝 Description 🔒 Mutability 💻 Examples
🔢 Int
Represents whole/integral numbers. Python integers have unlimited precision and no overflow. Immutable
# Integer examples
a = 10
type(a) # <class 'int'>
big = 123456789012345
🔢 Float
Represents decimal/floating point numbers using IEEE 754 double precision standard. Immutable
# Float examples
b = 10.5
type(b) # <class 'float'>
sci = 1.5e-4
🔢 Complex
Represents complex numbers with real and imaginary parts. Useful for mathematical computations. Immutable
# Complex examples
c = 10+5j
c.real # 10.0
c.imag # 5.0
✅ Bool
Represents logical values. Only two values: True and False. Subclass of int where True=1, False=0. Immutable
# Boolean examples
flag = True
flag = False
type(flag) # <class 'bool'>
📝 Str
Represents sequence of Unicode characters. Supports rich text operations and formatting. Immutable
# String examples
s = 'hema'
s = "hema"
s = '''Hema Software Solutions'''
🔐 Bytes
Represents sequence of byte values from 0-255. Used for binary data and file operations. Immutable
# Bytes examples
list = [1,2,3,4]
b = bytes(list)
type(b) # <class 'bytes'>
🔐 ByteArray
Mutable sequence of byte values from 0-255. Allows in-place modifications unlike bytes. Mutable
# ByteArray examples
list = [10,20,30]
ba = bytearray(list)
type(ba) # <class 'bytearray'>
🎯 Range
Represents range of values efficiently. Memory-optimized for generating number sequences. Immutable
# Range examples
r = range(10)
r1 = range(0,10)
r2 = range(0,10,2)
📚 List
Ordered collection of objects. Supports indexing, slicing, and dynamic resizing. Mutable
# List examples
l = [10,11,12,13,14,15]
type(l) # <class 'list'>
📦 Tuple
Ordered collection of objects. Immutable alternative to lists, perfect for fixed data. Immutable
# Tuple examples
t = (1,2,3,4,5)
type(t) # <class 'tuple'>
🎲 Set
Unordered collection of unique objects. Supports mathematical set operations. Mutable
# Set examples
s = {1,2,3,4,5,6}
type(s) # <class 'set'>
❄️ FrozenSet
Immutable version of set. Unordered collection of unique objects that cannot be modified. Immutable
# FrozenSet examples
s = {11,2,3,'Hema',100}
fs = frozenset(s)
type(fs) # <class 'frozenset'>
🗂️ Dict
Collection of key-value pairs. Ordered since Python 3.7 with O(1) average lookup time. Mutable
# Dict examples
d = {101:'hema', 102:'ravi',
     103:'hari'}
type(d) # <class 'dict'>

🚫 None Data Type

None represents nothing or no value associated. If the value is not available, then to handle such cases None is introduced. It's similar to null value in Java.
def process_data(): data = "Processing..." # No explicit return statement result = process_data() print(result) # Output: None # None comparison if result is None: print("No value returned")
