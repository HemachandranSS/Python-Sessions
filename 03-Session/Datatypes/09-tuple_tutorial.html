🐍 Python Tuples

The Immutable Data Structure

📝 What are Tuples?

Tuples are ordered collections of items that are immutable (cannot be changed after creation). Think of them as the "read-only" version of lists!

📋 Lists

✅ Mutable (changeable)

✅ Use square brackets [ ]

✅ Can add/remove items

✅ Can modify existing items

📦 Tuples

🔒 Immutable (unchangeable)

🔒 Use parentheses ( )

❌ Cannot add/remove items

❌ Cannot modify existing items

🎯 Creating Tuples

# Creating a tuple
t = (10, 20, 30, 40)
print(type(t))
# Output: <class 'tuple'>
(
10
20
30
40
)

🤔 When to Use Tuples?

✅ Perfect for:

  • Coordinates: (x, y, z)
  • RGB colors: (255, 128, 0)
  • Database records that shouldn't change
  • Function return values with multiple items
  • Configuration settings
  • Dictionary keys (when you need composite keys)
# Real-world examples
coordinates = (10.5, 20.3)
rgb_color = (255, 128, 0)
person_info = ("John", 25, "Engineer")
dimensions = (1920, 1080)

🎓 Summary

Tuples are immutable sequences that provide a secure way to store data that shouldn't change. While they lack the flexibility of lists, they offer better performance and data integrity. Remember: "Tuples are the read-only version of lists!"
