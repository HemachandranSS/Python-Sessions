What is bytearray?

bytearray is a mutable sequence of integers in the range 0-255. Unlike bytes, which is immutable, bytearray allows you to modify its elements after creation.

⚡
Key Difference

The main difference from bytes is mutability. While bytes objects cannot be changed after creation, bytearray elements can be modified, inserted, or removed.

🎯
Valid Range

Each element must be an integer between 0 and 255 (inclusive). Values outside this range will raise a ValueError.

📝 Code Example Analysis

x = [10, 20, 30, 40]
b = bytearray(x)
for i in b: print(i)

20
30
40
b[0] = 100 # This modifies the first element

Explanation: This example shows how bytearray can be created from a list and how its elements can be modified. The first element changes from 10 to 100.

❌ Error Example

x = [10, 256]
b = bytearray(x)
ValueError: byte must be in range(0, 256)
Why this fails: The value 256 is outside the valid range (0-255). Each byte can only represent values from 0 to 255.

🔄 Mutability

Unlike bytes, bytearray elements can be changed after creation using index assignment.

🔢 Range Validation

All values must be integers between 0 and 255. Values outside this range raise ValueError.

📊 Memory Efficient

Each element occupies exactly one byte in memory, making it efficient for binary data operations.

🔧 Flexible Creation

Can be created from lists, strings (with encoding), other bytearrays, or specified size.

⚡ Performance

Faster than lists for byte operations and provides direct memory access for binary data.

🌐 Use Cases

Perfect for network protocols, file I/O, image processing, and any binary data manipulation.
