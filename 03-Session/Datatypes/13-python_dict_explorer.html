📚 What is a Dictionary?

A dictionary in Python is a collection of key-value pairs. Think of it like a real dictionary where you look up a word (key) to find its meaning (value).

d = {101: 'hema', 102: 'ravi', 103: 'shiva'}
  • Stores data as key-value pairs
  • Keys must be unique
  • Values can be duplicated
  • Mutable (can be changed)

🔑 Key Properties

⚠️ Duplicate Keys: If you try to add a key that already exists, the old value will be replaced!
d = {101: 'hema', 102: 'ravi'} d[101] = 'sunny' # Replaces 'hema' print(d) # {101: 'sunny', 102: 'ravi'}
💡 Fun Fact: Dictionary order is preserved in Python 3.7+ (insertion order)

➕ Creating & Adding

You can create empty dictionaries and add items dynamically:

# Empty dictionary d = {} # Adding key-value pairs d['a'] = 'apple' d['b'] = 'banana' print(d) # {'a': 'apple', 'b': 'banana'}

🔧 Common Operations

d = {'name': 'Alice', 'age': 25, 'city': 'NYC'} # Accessing values print(d['name']) # Alice print(d.get('age')) # 25 # Checking if key exists if 'city' in d: print("City found!") # Getting all keys/values print(d.keys()) # dict_keys(['name', 'age', 'city']) print(d.values()) # dict_values(['Alice', 25, 'NYC'])

🎯 Data Type Notes

  • bytes/bytearray: Used for binary data (images, videos)
  • Python 2 vs 3: No separate 'long' type in Python 3
  • No char type: Single characters are just strings
  • Dictionary mutability: Can modify after creation
Modern Python automatically handles large integers and character representation seamlessly!
