What is Polymorphism?

Polymorphism allows objects of different types to be treated as objects of a common super type. It's a fundamental concept in object-oriented programming that enables flexibility and reusability.

Real-world Examples:

Example 1: Yourself is the best example of polymorphism. In front of your parents you have one type of behaviour and with friends another type of behaviour. Same person but different behaviours at different places.

Example 2: + operator acts as concatenation for strings and arithmetic addition for numbers.

Example 3: * operator acts as multiplication for numbers and repetition operator for strings.

Example 4: The same method with different implementations in Parent class and child classes (method overriding).

1. Duck Typing Philosophy of Python

Python follows the principle: "If it walks like a duck and talks like a duck, it must be a duck." In Python, we cannot specify types explicitly. Based on the provided value at runtime, the type is considered automatically.

Duck Typing Example 
class Duck:
    def talk(self):
        print('Quack.. Quack..')

class Dog:
    def talk(self):
        print('Bow Bow..')

class Cat:
    def talk(self):
        print('Meow Meow..')

class Goat:
    def talk(self):
        print('Myaah Myaah..')

def f1(obj):
    obj.talk()

animals = [Duck(), Cat(), Dog(), Goat()]
for animal in animals:
    f1(animal)

Output:

Quack.. Quack.. Meow Meow.. Bow Bow.. Myaah Myaah..
Problem: If an object doesn't contain the required method, we get an AttributeError. We can solve this using hasattr() function.
Using hasattr() to Check Methods 
class Duck:
    def talk(self):
        print('Quack.. Quack..')

class Human:
    def talk(self):
        print('Hello Hi...')

class Dog:
    def bark(self):
        print('Bow Bow..')

def f1(obj):
    if hasattr(obj, 'talk'):
        obj.talk()
    elif hasattr(obj, 'bark'):
        obj.bark()

d = Duck()
f1(d)

h = Human()
f1(h)

dog = Dog()
f1(dog)

Output:

Quack.. Quack.. Hello Hi... Bow Bow..

2. Overloading

Using the same operator or methods for different purposes.

Operator Overloading

Same operator for multiple purposes

Method Overloading

Same method name, different parameters

Constructor Overloading

Multiple constructors with different parameters

2.1 Operator Overloading

Python supports operator overloading by using special "magic methods" (methods with double underscores).

Basic Operator Overloading Examples 
# + operator for different purposes
print(10 + 20)           # 30 (arithmetic addition)
print('Hema ' + 'Soft')  # Hema Soft (string concatenation)

# * operator for different purposes
print(10 * 20)           # 200 (multiplication)
print('Hema ' * 3)       # Hema Hema Hema (string repetition)
Overloading + Operator for Custom Class 
class Book:
    def __init__(self, pages):
        self.pages = pages
    
    def __add__(self, other):
        return self.pages + other.pages

b1 = Book(100)
b2 = Book(200)
print('The Total Number of Pages:', b1 + b2)

Output:

The Total Number of Pages: 300

Overloading > and <= Operators 
class Student:
    def __init__(self, name, marks):
        self.name = name
        self.marks = marks
    
    def __gt__(self, other):
        return self.marks > other.marks
    
    def __le__(self, other):
        return self.marks <= other.marks

print("10 > 20 =", 10 > 20)
s1 = Student("Hema", 100)
s2 = Student("Ravi", 200)
print("s1 > s2 =", s1 > s2)
print("s1 < s2 =", s1 < s2)  # Uses __gt__ in reverse
print("s1 <= s2 =", s1 <= s2)
print("s1 >= s2 =", s1 >= s2)  # Uses __le__ in reverse

Output:

10 > 20 = False s1 > s2 = False s1 < s2 = True s1 <= s2 = True s1 >= s2 = False
Overloading * Operator for Employee Class 
class Employee:
    def __init__(self, name, salary):
        self.name = name
        self.salary = salary
    
    def __mul__(self, other):
        return self.salary * other.days

class TimeSheet:
    def __init__(self, name, days):
        self.name = name
        self.days = days

e = Employee('Hema', 500)
t = TimeSheet('Hema', 25)
print('This Month Salary:', e * t)

Output:

This Month Salary: 12500

2.2 Method Overloading

Important: Method overloading is not directly supported in Python. If we declare multiple methods with the same name, Python considers only the last method.
Method Overloading Attempt (Fails) 
class Test:
    def m1(self):
        print('no-arg method')
    
    def m1(self, a):
        print('one-arg method')
    
    def m1(self, a, b):
        print('two-arg method')

t = Test()
# t.m1()        # Error
# t.m1(10)      # Error
t.m1(10, 20)   # Works

Output:

two-arg method

Solutions for Method Overloading Requirements:

Using Default Arguments 
class Test:
    def sum(self, a=None, b=None, c=None):
        if a is not None and b is not None and c is not None:
            print('The Sum of 3 Numbers:', a + b + c)
        elif a is not None and b is not None:
            print('The Sum of 2 Numbers:', a + b)
        else:
            print('Please provide 2 or 3 arguments')

t = Test()
t.sum(10, 20)
t.sum(10, 20, 30)
t.sum(10)

Output:

The Sum of 2 Numbers: 30 The Sum of 3 Numbers: 60 Please provide 2 or 3 arguments
Using Variable Number of Arguments (*args) 
class Test:
    def sum(self, *args):
        total = 0
        for x in args:
            total += x
        print('The Sum:', total)

t = Test()
t.sum(10, 20)
t.sum(10, 20, 30)
t.sum(10)
t.sum()

Output:

The Sum: 30 The Sum: 60 The Sum: 10 The Sum: 0

3. Overriding

Overriding allows a child class to provide a specific implementation of a method that is already provided by its parent class.

3.1 Method Overriding

Basic Method Overriding Example 
class Parent:
    def property(self):
        print('Gold+Land+Cash+Power')
    
    def marry(self):
        print('Arranged Marriage')

class Child(Parent):
    def marry(self):
        print('Love Marriage')

c = Child()
c.property()
c.marry()

Output:

Gold+Land+Cash+Power Love Marriage
Note: From the overriding method of the child class, we can call the parent class method using super().
Calling Parent Method with super() 
class Parent:
    def property(self):
        print('Gold+Land+Cash+Power')
    
    def marry(self):
        print('Arranged Marriage')

class Child(Parent):
    def marry(self):
        super().marry()  # Call parent method
        print('Love Marriage')

c = Child()
c.property()
c.marry()

Output:

Gold+Land+Cash+Power Arranged Marriage Love Marriage

3.2 Constructor Overriding

Constructor Overriding Example 
class Parent:
    def __init__(self):
        print('Parent Constructor')

class Child(Parent):
    def __init__(self):
        print('Child Constructor')

c = Child()

Output:

Child Constructor
Note: If the child class doesn't contain a constructor, the parent class constructor will be executed. We can call the parent class constructor using super().
Calling Parent Constructor with super() 
class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age

class Employee(Person):
    def __init__(self, name, age, eno, esal):
        super().__init__(name, age)  # Call parent constructor
        self.eno = eno
        self.esal = esal
    
    def display(self):
        print('Employee Name:', self.name)
        print('Employee Age:', self.age)
        print('Employee Number:', self.eno)
        print('Employee Salary:', self.esal)

e1 = Employee('Hema', 48, 872425, 26000)
e1.display()

e2 = Employee('Sunny', 39, 872426, 36000)
e2.display()

Output:

Employee Name: Hema Employee Age: 48 Employee Number: 872425 Employee Salary: 26000 Employee Name: Sunny Employee Age: 39 Employee Number: 872426 Employee Salary: 36000
