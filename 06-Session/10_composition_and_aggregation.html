Composition vs Aggregation

Understanding Object Relationships in Python

Composition

Definition: Without existing container object if there is no chance of existing contained object, then the container and contained objects are strongly associated. This strong association is called Composition.

(Container Object)
Composition
Department Object
(Contained Object)

Example: University and Departments

A University contains several Departments. Without an existing University object, there is no chance of a Department object existing. Hence University and Department objects are strongly associated (Composition).

Aggregation

Definition: Without existing container object if there is a chance of existing contained object, then the container and contained objects are weakly associated. This weak association is called Aggregation.

Department Object
(Container Object)
Aggregation
Professor Object
(Contained Object)

Example: Department and Professors

A Department contains several Professors. Without an existing Department, there may still be a chance of a Professor existing (they could move to another department). Hence Department and Professor objects are weakly associated (Aggregation).

Coding Example

This example demonstrates both Composition and Aggregation in a single Python class. Instance variables represent Composition while static/class variables represent Aggregation.

class Student:
    collegeName = 'HEMASOFT' # Static variable (Aggregation)

    def __init__(self, name):
        self.name = name # Instance variable (Composition)

# Testing the class
print(Student.collegeName) # Accessing static variable
s = Student('Hema') # Creating object with name 'Hema'
print(s.name) # Accessing instance variable
Output:
HEMASOFT
Hema

Explanation: Without existing Student object there is no chance of existing his name. Hence Student Object and his name are strongly associated (Composition). But without existing Student object there may be a chance of existing collegeName. Hence Student object and collegeName are weakly associated (Aggregation).

Conclusion

The relation between an object and its instance variables is always Composition whereas the relation between an object and static variables is Aggregation.

Important Note

Note: Whenever we are creating child class object then child class constructor will be executed. If the child class does not contain constructor then parent class constructor will be executed, but parent object won't be created.

class P:
    def __init__(self):
        print(id(self))

class C(P):
    pass

c = C()
print(id(c))
Output:
6207088
6207088

Explanation: Both IDs are the same because only one object (child object) is created, and the parent constructor is executed for that child object.

class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age

class Student(Person):
    def __init__(self, name, age, rollno, marks):
        super().__init__(name, age)
        self.rollno = rollno
        self.marks = marks

    def __str__(self):
        return 'Name={}\nAge={}\nRollno={}\nMarks={}'.format(self.name, self.age, self.rollno, self.marks)

s1 = Student('Hema', 48, 101, 90)
print(s1)
Output:
Name=Hema
Age=48
Rollno=101
Marks=90

Note: In the above example, when we create a child class object, both parent and child class constructors are executed to perform initialization of the child object.
