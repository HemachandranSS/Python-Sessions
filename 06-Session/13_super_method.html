Python super() Method

Complete Guide with Examples and Best Practices

The super() method is a built-in Python function that provides a way to call methods from a parent class. It's especially useful in inheritance scenarios for calling superclass constructors, accessing variables, and invoking methods from child classes.

Introduction to super()

super() returns a temporary object of the superclass that allows you to call its methods. This is particularly useful in inheritance hierarchies where you want to extend the functionality of a parent class without completely overriding it.

Key Benefits:

  • Allows child classes to extend parent class methods
  • Helps avoid hardcoding parent class names
  • Supports cooperative multiple inheritance
  • Maintains proper method resolution order (MRO)

Demo Program 1: Basic super() Usage

This example demonstrates how to use super() to call parent class constructor and methods.

Person-Student Inheritance Example 
class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age
    
    def display(self):
        print('Name:', self.name)
        print('Age:', self.age)

class Student(Person):
    def __init__(self, name, age, rollno, marks):
        # Call parent class constructor
        super().__init__(name, age)
        self.rollno = rollno
        self.marks = marks
    
    def display(self):
        # Call parent class display method
        super().display()
        print('Roll No:', self.rollno)
        print('Marks:', self.marks)

s1 = Student('Hema', 22, 101, 90)
s1.display()

Output:

Name: Hema Age: 22 Roll No: 101 Marks: 90
Explanation: In the above program, we use super() to call both the parent class constructor (__init__) and the display() method. This allows the Student class to extend the Person class functionality while reusing existing code.

Demo Program 2: Accessing Various Parent Members

This example shows how to use super() to access different types of parent class members (instance methods, class methods, static methods, and variables).

Accessing Different Member Types 
class P:
    a = 10  # Class/static variable
    
    def __init__(self):
        self.b = 10  # Instance variable
    
    def m1(self):
        print('Parent instance method')
    
    @classmethod
    def m2(cls):
        print('Parent class method')
    
    @staticmethod
    def m3():
        print('Parent static method')

class C(P):
    a = 888  # Overriding class variable
    
    def __init__(self):
        self.b = 999  # Overriding instance variable
        # Call parent constructor
        super().__init__()
        # Access parent class variable
        print(super().a)
        # Call parent methods
        super().m1()
        super().m2()
        super().m3()

c = C()

Output:

10 Parent instance method Parent class method Parent static method
Note: In this example, super() is used to access the parent class's static variable (a) and call all three types of methods (instance method, class method, and static method). Notice that super().a accesses the parent class's version of the variable, not the child's overridden version.

Calling Methods of a Specific Super Class

When you need to call a method from a specific ancestor class (not just the immediate parent), you can use these approaches:

Approach 1: super(D, self).m1() - Calls m1() method of super class of D
Approach 2: A.m1(self) - Directly calls A class m1() method
Calling Specific Ancestor Class Method 
class A:
    def m1(self):
        print('A class Method')

class B(A):
    def m1(self):
        print('B class Method')

class C(B):
    def m1(self):
        print('C class Method')

class D(C):
    def m1(self):
        print('D class Method')

class E(D):
    def m1(self):
        # Directly call A class method, skipping B, C, D
        A.m1(self)

e = E()
e.m1()

Output:

A class Method
Explanation: The class E directly calls the m1() method from class A using A.m1(self), bypassing the implementations in classes B, C, and D.

Important Cases and Restrictions

Case 1: Accessing Parent Class Variables

From child class, we are not allowed to access parent class instance variables using super(). We must use self. However, we can access parent class static/class variables using super().

Variable Access Example 
class P:
    a = 10  # Static/class variable
    
    def __init__(self):
        self.b = 20  # Instance variable

class C(P):
    def m1(self):
        print(super().a)   # Valid - accessing static variable
        print(self.b)      # Valid - accessing instance variable
        # print(super().b) # Invalid - cannot access instance variable

c = C()
c.m1()

Output:

10 20 # Note: super().b would raise: AttributeError: 'super' object has no attribute 'b'
Case 2: Access from Constructor and Instance Methods

From child class constructor and instance methods, we can access parent class instance method, static method, and class method using super().

Access from Constructor and Instance Method 
class P:
    def __init__(self):
        print('Parent Constructor')
    
    def m1(self):
        print('Parent instance method')
    
    @classmethod
    def m2(cls):
        print('Parent class method')
    
    @staticmethod
    def m3():
        print('Parent static method')

class C(P):
    def __init__(self):
        super().__init__()      # Call parent constructor
        super().m1()           # Call parent instance method
        super().m2()           # Call parent class method
        super().m3()           # Call parent static method
    
    def m1(self):
        super().__init__()      # Call parent constructor
        super().m1()           # Call parent instance method
        super().m2()           # Call parent class method
        super().m3()           # Call parent static method

c = C()
c.m1()

Output:

Parent Constructor Parent instance method Parent class method Parent static method Parent Constructor Parent instance method Parent class method Parent static method
Case 3: Access from Class Method

From child class class method, we cannot directly access parent class instance methods and constructors using super() (but indirectly possible). We can access parent class static and class methods.

Access from Class Method 
class P:
    def __init__(self):
        print('Parent Constructor')
    
    def m1(self):
        print('Parent instance method')
    
    @classmethod
    def m2(cls):
        print('Parent class method')
    
    @staticmethod
    def m3():
        print('Parent static method')

class C(P):
    @classmethod
    def m1(cls):
        # super().__init__()  # Invalid - cannot call constructor
        # super().m1()        # Invalid - cannot call instance method
        super().m2()         # Valid - can call class method
        super().m3()         # Valid - can call static method

C.m1()

Output:

Parent class method Parent static method
How to call parent instance methods from class method:
You can use super(CurrentClass, cls).method(cls) syntax to call parent instance methods from a class method.
Calling Parent Instance Methods from Class Method 
class A:
    def __init__(self):
        print('Parent constructor')
    
    def m1(self):
        print('Parent instance method')

class B(A):
    @classmethod
    def m2(cls):
        super(B, cls).__init__(cls)
        super(B, cls).m1(cls)

B.m2()

Output:

Parent constructor Parent instance method
Case 4: Access from Static Method

In child class static method, we are generally not allowed to use super() (but can use it in a special way).

Invalid super() in Static Method 
class P:
    def __init__(self):
        print('Parent Constructor')
    
    def m1(self):
        print('Parent instance method')
    
    @classmethod
    def m2(cls):
        print('Parent class method')
    
    @staticmethod
    def m3():
        print('Parent static method')

class C(P):
    @staticmethod
    def m1():
        # All of these are invalid in static method:
        # super().m1()  # Invalid
        # super().m2()  # Invalid
        # super().m3()  # Invalid
        pass

C.m1()
Error: Using super() without arguments in a static method raises: RuntimeError: super(): no arguments
How to call parent static method from child static method:
You can use super(CurrentClass, CurrentClass).method() syntax.
Calling Parent Static Method from Child Static Method 
class A:
    @staticmethod
    def m1():
        print('Parent static method')

class B(A):
    @staticmethod
    def m2():
        super(B, B).m1()

B.m2()

Output:

Parent static method
