Introduction to Modules

A group of functions, variables and classes saved to a file, which is nothing but a module. Every Python file (.py) acts as a module.

Note: All instances of "durga" have been replaced with "hema" throughout this tutorial.

Example: hemamath.py

x = 888 def add(a, b): print("The Sum:", a + b) def product(a, b): print("The Product:", a * b)

The hemamath module contains one variable and 2 functions. To use members of a module in our program, we should import that module.

Example: test.py

import hemamath print(hemamath.x) hemamath.add(10, 20) hemamath.product(10, 20)
Output:
888
The Sum: 30
The Product: 200

Note: Whenever we use a module in our program, a compiled file (.pyc) will be generated and stored in the hard disk permanently.

Importing Modules

Python provides multiple ways to import modules and their members.

Various Possibilities of import:

  1. import modulename
  2. import module1, module2, module3
  3. import module1 as m
  4. import module1 as m1, module2 as m2, module3
  5. from module import member
  6. from module import member1, member2, member3
  7. from module import member1 as x
  8. from module import *

Using from ... import:

from hemamath import x, add print(x) add(10, 20) # product(10, 20) # NameError: name 'product' is not defined

Importing all members:

from hemamath import * print(x) add(10, 20) product(10, 20)
Page 3-4

Module and Member Aliasing

Module Aliasing:

import hemamath as m print(m.x) m.add(10, 20) m.product(10, 20)

Member Aliasing:

from hemamath import x as y, add as sum print(y) sum(10, 20)

Important: Once we define an alias name, we should use the alias name only and not the original name.

from hemamath import x as y print(x) # NameError: name 'x' is not defined

Reloading Modules

By default, a module will be loaded only once even if we import it multiple times.

Example: module1.py

print("This is from module1")

Example: test.py

import module1 import module1 import module1 import module1 print("This is test module")
Output:
This is from module1
This is test module

The problem with this approach is that after loading a module, if it's updated outside, the updated version is not available to our program.

Solution: Explicit reloading using imp module

import module1 import module1 from imp import reload reload(module1) reload(module1) reload(module1) print("This is test module")
Output:
This is from module1
This is from module1
This is from module1
This is from module1
This is test module

Note: The main advantage of explicit module reloading is we can ensure that the updated version is always available to our program.

Finding Members with dir() Function

Python provides the built-in function dir() to list out all members of a module.

x = 10 y = 20 def f1(): print("Hello") print(dir()) # List all members of current module
Output:
['__annotations__', '__builtins__', '__cached__', '__doc__', '__file__', '__loader__', '__name__', '__package__', '__spec__', 'f1', 'x', 'y']

Listing members of a specific module:

import hemamath print(dir(hemamath))
Output:
['__builtins__', '__cached__', '__doc__', '__file__', '__loader__', '__name__', '__package__', '__spec__', 'add', 'product', 'x']

Note: For every module at the time of execution, Python interpreter adds some special properties automatically for internal use:

  • __builtins__
  • __cached__
  • __doc__
  • __file__
  • __loader__
  • __name__
  • __package__
  • __spec__

The Special Variable __name__

For every Python program, a special variable __name__ is added internally. This variable stores information about whether the program is executed as an individual program or as a module.

  • If executed as an individual program → __name__ = "__main__"
  • If executed as a module from another program → __name__ = module_name

Example: module1.py

def f1(): if __name__ == '__main__': print("The code executed as a program") else: print("The code executed as a module from some other program") f1()

Example: test.py

import module1 module1.f1()
Output when running module1.py directly:
The code executed as a program

Output when running test.py:
The code executed as a module from some other program
The code executed as a module from some other program

Working with math Module

Python provides the built-in math module for mathematical operations.

sqrt(x)
Returns square root of x
ceil(x)
Returns smallest integer ≥ x
floor(x)
Returns largest integer ≤ x
fabs(x)
Returns absolute value of x
log(x)
Returns natural logarithm of x
sin(x)
Returns sine of x radians
tan(x)
Returns tangent of x radians
from math import * print(sqrt(4)) print(ceil(10.1)) print(floor(10.1)) print(fabs(-10.6)) print(fabs(10.6))
Output:
2.0
11
10
10.6
10.6

Help for modules: We can find help for any module using the help() function:

import math help(math)

Working with random Module

The random module defines several functions to generate random numbers, useful in games, cryptography, and authentication.

1) random() Function

Generates a float value between 0 and 1 (0 < x < 1)

from random import * for i in range(10): print(random())

2) randint() Function

Generates a random integer between two given numbers (inclusive)

from random import * for i in range(10): print(randint(1, 100))

3) uniform() Function

Returns random float values between 2 given numbers (not inclusive)

from random import * for i in range(10): print(uniform(1, 10))

4) randrange() Function

Returns a random number from a range

randrange(10) # 0 to 9 randrange(1, 11) # 1 to 10 randrange(1, 11, 2) # 1, 3, 5, 7, 9

5) choice() Function

Returns a random object from the given list or tuple

from random import * list = ["Sunny", "Bunny", "Chinny", "Vinny", "Pinny"] for i in range(10): print(choice(list))

Quick Reference:

  • random() → 0 < x < 1 (not inclusive)
  • randint(x, y) → x ≤ n ≤ y (inclusive)
  • uniform(x, y) → x < n < y (not inclusive)
