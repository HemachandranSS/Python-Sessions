Python print() — Complete Output Guide

Master the print() function with comprehensive examples and best practices — with Durga replaced by Hema.

We can use the print() function to display output in Python. Below are all the forms, rules, and practical examples.

Form-1 print() without any argument

Simply prints a new line character (blank line).

print()
# Output: (blank line)

Form-2 Printing strings and escape characters

  1. print(String)
  2. print("Hello World")
  3. Escape characters work too:
print("Hello \n World")    # Hello
                              #  World
print("Hello\tWorld")     # Hello    World

Repeat strings using the repetition operator *:

print(10 * "Hello")   # prints "Hello" 10 times
print("Hello" * 10)       # same effect

Concatenation using +:

print("Hello" + "World")  # HelloWorld
Important Notes:
  • If both operands are strings, + concatenates them.
  • If one operand is a string and the other is a non-string (e.g., int), you'll get a TypeError.
  • If both operands are numbers, + adds them arithmetically.

Example showing the difference:

print("Hello" + "World")   # HelloWorld
print("Hello", "World")     # Hello World (note the space)

Form-3 print() with variable number of arguments

By default, values are separated by a space. Use sep to change the separator.

a, b, c = 10, 20, 30
print("The Values are :", a, b, c)
# Output: The Values are : 10 20 30

print(a, b, c, sep=',')   # 10,20,30
print(a, b, c, sep=':')   # 10:20:30

Form-4 print() with end attribute

The default value for end is '\n' (new line). Use end to stay on same line.

print("Hello")
print("Hema")
print("Soft")
# Output:
# Hello
# Hema
# Soft

# To print on same line:
print("Hello", end=' ')
print("Hema", end=' ')
print("Soft")
# Output: Hello Hema Soft

Form-5 print(object) — printing collections

You can pass any object (list, tuple, set, dict) to print().

l = [10, 20, 30, 40]
t = (10, 20, 30, 40)
print(l)   # [10, 20, 30, 40]
print(t)   # (10, 20, 30, 40)

Form-6 print(string, variable list)

s = "Hema"
a = 48
s1 = "Java"
s2 = "Python"
print("Hello", s, "Your Age is", a)
# Output: Hello Hema Your Age is 48
print("You are teaching", s1, "and", s2)
# Output: You are teaching Java and Python

Form-7 Formatted strings using % placeholders

Placeholders:

  • %i / %d — integers
  • %f — float
  • %s — string
a = 10
b = 20
c = 30
print("a value is %i" % a)
print("b value is %d and c value is %d" % (b, c))
# Output:
# a value is 10
# b value is 20 and c value is 30

s = "Hema"
my_list = [10, 20, 30, 40]
print("Hello %s ...The List of Items are %s" % (s, my_list))
# Output: Hello Hema ...The List of Items are [10, 20, 30, 40]

Form-8 print() with replacement operator {} (str.format)

name = "Hema"
salary = 10000
gf = "Sunny"
print("Hello {0} your salary is {1} and Your Friend {2} is waiting".format(name, salary, gf))
print("Hello {x} your salary is {y} and Your Friend {z} is waiting".format(x=name, y=salary, z=gf))
# Output:
# Hello Hema your salary is 10000 and Your Friend Sunny is waiting
# Hello Hema your salary is 10000 and Your Friend Sunny is waiting
