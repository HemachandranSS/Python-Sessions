Command Line Arguments

Learn how to pass and access command line arguments in Python using sys.argv. Command line arguments allow you to pass data to your program when it starts.

argv is not an Array; it is a list available in the sys module.

How Command Line Arguments Work

python test.py 10 20 30

Becomes accessible as sys.argv

argv[0]
test.py
argv[1]
10
argv[2]
20
argv[3]
30
Important Note
argv[0] represents the name of the program (script). The first actual command line argument is argv[1].

Code Examples

Check Type of argv

from sys import argv print(type(argv)) # Run from command line: # python test.py
Output:
<class 'list'>

Display Command Line Arguments

from sys import argv print("The Number of Command Line Arguments:", len(argv)) print("The List of Command Line Arguments:", argv) print("Command Line Arguments one by one:") for x in argv: print(x) # Example run: # python test.py 10 20 30
Output:
The Number of Command Line Arguments: 4 The List of Command Line Arguments: ['test.py', '10', '20', '30'] Command Line Arguments one by one: test.py 10 20 30

Sum Numeric Command Line Arguments

from sys import argv sum = 0 args = argv[1:] for x in args: n = int(x) sum = sum + n print("The Sum:", sum) # Example run: # python test.py 10 20 30 40
Output:
The Sum: 100

Important Notes

Note 1: Handling Spaces in Arguments

By default the space character separates arguments. If an argument itself contains spaces, enclose it in double quotes.

from sys import argv print(argv[1]) # Examples: # python test.py Sunny Leone # Output: Sunny # python test.py 'Sunny Leone' # Output: 'Sunny # python test.py "Sunny Leone" # Output: Sunny Leone
Output (with double quotes):
Sunny Leone

Note 2: Arguments are Strings

Command line arguments are strings. Convert them if needed for numeric operations.

from sys import argv print(argv[1] + argv[2]) # string concatenation print(int(argv[1]) + int(argv[2])) # integer addition # Example: # python test.py 10 20
Output:
1020 30

Note 3: Index Out of Range

Accessing out-of-range index raises IndexError.

from sys import argv print(argv[100]) # Example:
Error:
IndexError: list index out of range
Pro Tip
For advanced command-line parsing with automatic help messages, validation, and type conversion, use the argparse module instead of manually parsing sys.argv.
