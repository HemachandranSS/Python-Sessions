Python String Data Type

The most commonly used object in any project and in any programming language

What is String?

Any sequence of characters within either single quotes or double quotes is considered as a String.

# Syntax s = 'hema' s = "hema"
Note:

In most other languages like C, C++, Java, a single character within single quotes is treated as char data type value. But in Python we don't have char data type. Hence it is treated as String only.

Example: Character Type
>>> ch = 'a' >>> type(ch) <class 'str'>

Multi-line String Literals

We can define multi-line String literals by using triple single or double quotes.

>>> s = '''hema software solutions'''
Examples with Quotes
1) s = 'This is ' single quote symbol' # Invalid 2) s = 'This is \' single quote symbol' # Valid 3) s = "This is ' single quote symbol" # Valid 4) s = 'This is " double quotes symbol' # Valid 5) s = 'The "Python Notes" by 'hema' is very helpful' # Invalid 6) s = "The "Python Notes" by 'hema' is very helpful" # Invalid 7) s = 'The \"Python Notes\" by \'hema\' is very helpful' # Valid 8) s = '''The "Python Notes" by 'hema' is very helpful''' # Valid

Accessing Characters of a String

We can access characters of a string by using:

  1. By using index
  2. By using slice operator

1) Accessing Characters By using Index

Python supports both +ve and -ve Index:

  • +ve Index means Left to Right (Forward Direction)
  • -ve Index means Right to Left (Backward Direction)
>>> s = 'hema' >>> s[0] 'h' >>> s[3] 'a' >>> s[-1] 'a' >>> s[10] IndexError: string index out of range
Program: Display Characters by Index
s = input("Enter Some String: ") i = 0 for x in s: print(f"The character at +ve index {i} and -ve index {i-len(s)} is {x}") i = i + 1
Input:
Enter Some String: hema
Output:
The character at +ve index 0 and -ve index -4 is h The character at +ve index 1 and -ve index -3 is e The character at +ve index 2 and -ve index -2 is m The character at +ve index 3 and -ve index -1 is a

2) Accessing Characters by using Slice Operator

Syntax: s[begin:end:step]

>>> s = "Learning Python is very very easy!!!" >>> s[1:7:1] 'earnin' >>> s[1:7] 'earnin' >>> s[1:7:2] 'eri' >>> s[:7] 'Learnin' >>> s[7:] 'g Python is very very easy!!!' >>> s[::] 'Learning Python is very very easy!!!' >>> s[:] 'Learning Python is very very easy!!!' >>> s[::-1] '!!!ysae yrev yrev si nohtyP gninraeL'
Note:
  • If begin index is not specified, it starts from beginning
  • If end index is not specified, it goes to end of string
  • Default step value is 1
  • Slice operator never raises IndexError

Mathematical Operators for String

>>> print("hema" + "soft") hemasoft >>> print("hema" * 2) hemahema
Note:

1) To use + operator for Strings, both arguments must be str type
2) To use * operator for Strings, one argument must be str and other must be int

len() function

>>> s = 'hema' >>> print(len(s)) 4

String Methods

Method Description Example
strip() Remove spaces from both sides " hema ".strip() → "hema"
find() Find substring (returns -1 if not found) "hema".find('e') → 1
index() Find substring (raises ValueError if not found) "hema".index('e') → 1
count() Count occurrences of substring "abcabc".count('a') → 2
replace() Replace old string with new string "hema".replace('e','a') → "hama"
split() Split string into list "hema software".split() → ['hema', 'software']
join() Join list/tuple into string "-".join(['a','b','c']) → "a-b-c"
upper() Convert to uppercase "hema".upper() → "HEMA"
lower() Convert to lowercase "HEMA".lower() → "hema"
startswith() Check if string starts with substring "hema".startswith('h') → True
endswith() Check if string ends with substring "hema".endswith('a') → True

Important String Programs

1) Reverse a String
s = input("Enter Some String: ") # Method 1 print(s[::-1]) # Method 2 print(''.join(reversed(s)))

Easy very is Python Learning
3) Reverse Internal Content of Words

ameh erawtfoS snoituloS
4) Print Odd & Even Position Characters
s = input("Enter Some String: ") print("Characters at Even Position:", s[0::2]) print("Characters at Odd Position:", s[1::2])
Input:
Enter Some String: python
Output:
Characters at Even Position: pto Characters at Odd Position: yhn
5) Merge Two Strings Alternately
s1 = input("Enter First String: ") s2 = input("Enter Second String: ") output = '' i, j = 0, 0 while i < len(s1) or j < len(s2): if i < len(s1): output = output + s1[i] i += 1 if j < len(s2): output = output + s2[j] j += 1 print(output)
Input:
Enter First String: hema Enter Second String: ravisoft
Output:
hreamavisoft
6) Sort Characters: Alphabets then Numbers
s = input("Enter Some String: ") alphabets = ''.join(sorted([x for x in s if x.isalpha()])) numbers = ''.join(sorted([x for x in s if x.isdigit()])) output = alphabets + numbers print(output)
Input:
Enter Some String: B4A1D3
Output:
ABD134
7) Expand String (a4b3c2 → aaaabbbcc)
s = input("Enter Some String: ") output = '' for i in range(0, len(s), 2): char = s[i] count = int(s[i+1]) output += char * count print(output)
Input:
Enter Some String: a4b3c2
Output:
aaaabbbcc
8) Remove Duplicate Characters
s = input("Enter Some String: ") result = '' for char in s: if char not in result: result += char print(result)
Input:
Enter Some String: ABCABCABBCDE
Output:
ABCDE

String Formatting

name = 'hema' salary = 10000 age = 28 # Default formatting print("{}'s salary is {} and age is {}".format(name, salary, age)) # Positional arguments print("{0}'s salary is {1} and age is {2}".format(name, salary, age)) # Keyword arguments print("{n}'s salary is {s} and age is {a}".format(n=name, s=salary, a=age)) # F-strings (Python 3.6+) print(f"{name}'s salary is {salary} and age is {age}")
Number Formatting Examples
# Integer formatting print("Integer: {:5d}".format(123)) # ' 123' print("Integer: {:05d}".format(123)) # '00123' # Float formatting print("Float: {:8.3f}".format(123.4567)) # ' 123.457' print("Float: {:08.3f}".format(123.4567)) # '0123.457' # Number systems print("Binary: {:b}".format(10)) # '1010' print("Octal: {:o}".format(10)) # '12' print("Hex: {:x}".format(255)) # 'ff' print("Hex: {:X}".format(255)) # 'FF' # Alignment print("{:<10}".format("left")) # 'left ' print("{:>10}".format("right")) # ' right' print("{:^10}".format("center")) # ' center ' print("{:*^10}".format("center")) # '**center**'
Key Points about Strings:
  1. Strings are immutable in Python
  2. String objects support both positive and negative indexing
  3. Slice operator s[begin:end:step] is very powerful
  4. Python has rich set of string methods for manipulation
  5. Strings can be formatted using format() method or f-strings
  6. Special characters can be escaped using backslash (\)
  7. Triple quotes allow multi-line strings
