Introduction to Dictionary

We can use List, Tuple and Set to represent a group of individual objects as a single entity. If we want to represent a group of objects as key-value pairs then we should go for Dictionary.

Examples:

  • rollno --- name
  • phone number -- address
  • ipaddress --- domain name

Note: In C++ and Java Dictionaries are known as "Map" where as in Perl and Ruby it is known as "Hash".

Dictionary Characteristics:

  • Duplicate keys are not allowed but values can be duplicated
  • Hetrogeneous objects are allowed for both key and values
  • Insertion order is not preserved
  • Dictionaries are mutable
  • Dictionaries are dynamic
  • Indexing and slicing concepts are not applicable

How to Create Dictionary?

1. Empty Dictionary:

d = {} # OR d = dict()
# We can add entries as follows
d[100] = "hema"
d[200] = "ravi"
d[300] = "shiva"
print(d) # {100: 'hema', 200: 'ravi', 300: 'shiva'}

2. Dictionary with predefined data:

d = {100:'hema', 200:'ravi', 300:'shiva'}
# General format: d = {key:value, key:value}

How to Access Data from the Dictionary?

We can access data by using keys.

d = {100:'hema', 200:'ravi', 300:'shiva'}
print(d[100]) # hema
print(d[300]) # shiva

If the specified key is not available then we will get KeyError.

print(d[400]) # KeyError: 400

We can prevent this by checking whether key is already available or not by using in operator.

if 400 in d:
    print(d[400])

Note: has_key() function was available in Python 2 but not in Python 3. Hence we have to use in operator.

How to Update Dictionaries?

d[key] = value

  • If the key is not available then a new entry will be added to the dictionary with the specified key-value pair
  • If the key is already available then old value will be replaced with new value.
d = {100:"hema", 200:"ravi", 300:"shiva"}
print(d)
d[400] = "pavan"
print(d)
d[100] = "sunny"
print(d)
Output:
{100: 'hema', 200: 'ravi', 300: 'shiva'}
{100: 'hema', 200: 'ravi', 300: 'shiva', 400: 'pavan'}
{100: 'sunny', 200: 'ravi', 300: 'shiva', 400: 'pavan'}

How to Delete Elements from Dictionary?

1. del d[key] - Deletes entry associated with the specified key.

d = {100:"hema", 200:"ravi", 300:"shiva"}
print(d)
del d[100]
print(d)
del d[400] # KeyError: 400

2. d.clear() - Removes all entries from the dictionary.

d = {100:"hema", 200:"ravi", 300:"shiva"}
print(d)
d.clear()
print(d) # {}

3. del d - Deletes total dictionary.

d = {100:"hema", 200:"ravi", 300:"shiva"}
print(d)
del d
print(d) # NameError: name 'd' is not defined

Important Functions of Dictionary

1. dict() - To create a dictionary

d1 = dict() # Empty dictionary
d2 = dict({100:"hema", 200:"ravi"})
d3 = dict([(100,"hema"),(200,"shiva"),(300,"ravi")])

2. len() - Returns the number of items in the dictionary.

3. clear() - To remove all elements from the dictionary.

4. get() - To get the value associated with the key

d = {100:"hema", 200:"ravi", 300:"shiva"}
print(d[100]) # hema
print(d.get(100)) # hema
print(d.get(400)) # None
print(d.get(100,"Guest")) # hema
print(d.get(400,"Guest")) # Guest

5. pop() - Removes entry associated with specified key and returns value

d = {100:"hema", 200:"ravi", 300:"shiva"}
print(d.pop(100)) # hema
print(d) # {200: 'ravi', 300: 'shiva'}

6. popitem() - Removes arbitrary item and returns it

7. keys() - Returns all keys

d = {100:"hema", 200:"ravi", 300:"shiva"}
print(d.keys()) # dict_keys([100, 200, 300])

8. values() - Returns all values

9. items() - Returns key-value pairs as tuples

d = {100:"hema", 200:"ravi", 300:"shiva"}
for k,v in d.items():
    print(k, "--", v)

10. copy() - Creates duplicate dictionary (cloned copy)

d1 = d.copy()

11. setdefault()

d = {100:"hema", 200:"ravi", 300:"shiva"}
print(d.setdefault(400,"pavan")) # pavan
print(d) # {100: 'hema', 200: 'ravi', 300: 'shiva', 400: 'pavan'}
print(d.setdefault(100,"sachin")) # hema

12. update() - Adds all items from another dictionary

d.update(x) # All items in x added to d

Practice Programs

1. Enter Name and Percentage Marks in a Dictionary

rec = {}
n = int(input("Enter number of students: "))
i = 1
while i <= n:
    name = input("Enter Student Name: ")
    marks = input("Enter % of Marks of Student: ")
    rec[name] = marks
    i = i + 1
print("\nName of Student", "\t", "% of marks")
for x in rec:
    print("\t", x, "\t\t", rec[x])

2. Sum of Values in Dictionary

d = eval(input("Enter dictionary:"))
s = sum(d.values())
print("Sum=", s)

3. Occurrences of each Letter in String

word = input("Enter any word: ")
d = {}
for x in word:
    d[x] = d.get(x, 0) + 1
for k,v in d.items():
    print(k, "occurred ", v, " times")

4. Student Marks Dictionary

n = int(input("Enter the number of students: "))
d = {}
for i in range(n):
    name = input("Enter Student Name: ")
    marks = input("Enter Student Marks: ")
    d[name] = marks
while True:
    name = input("Enter Student Name to get Marks: ")
    marks = d.get(name, -1)
    if marks == -1:
        print("Student Not Found")
    else:
        print("The Marks of", name, "are", marks)
    option = input("Do you want to find another student marks[Yes|No]")
    if option == "No":
        break
print("Thanks for using our application")

Dictionary Comprehension

Comprehension concept applicable for dictionaries also.

squares = {x:x*x for x in range(1,6)}
print(squares)
doubles = {x:2*x for x in range(1,6)}
print(doubles)
Output:
{1: 1, 2: 4, 3: 9, 4: 16, 5: 25}
{1: 2, 2: 4, 3: 6, 4: 8, 5: 10}
