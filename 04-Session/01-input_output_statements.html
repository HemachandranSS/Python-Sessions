Input & Output

Learn how to read dynamic input from the keyboard and display output in Python. Master the input() function, eval(), and various techniques for handling user input.

Python 2 vs Python 3

Python 2
  • raw_input()
    Always returns a string
  • input()
    Evaluates input and returns natural type
# example
x = raw_input("Enter First Number:")
print(type(x)) # will print <type 'str'>
Python 3
  • input()
    Always returns a string (like Python 2's raw_input)
>> type(input("Enter value:"))
Enter value:10
<class 'str'>
Note
Python 3 removed raw_input(). The input() function now behaves like Python 2's raw_input().

Examples

Read Two Numbers (Multi-step)

Read two numbers and print their sum using separate type conversion steps.

x = input("Enter First Number:")
y = input("Enter Second Number:")
i = int(x)
j = int(y)
print("The Sum:", i + j)

# Sample run
# Enter First Number: 100
# Enter Second Number: 200
# The Sum: 300
Output:
Enter First Number: 100 Enter Second Number: 200 The Sum: 300

Read Two Numbers (Compact)

A more compact version using inline type conversion.

x = int(input("Enter First Number:"))
y = int(input("Enter Second Number:"))
print("The Sum:", x + y)

# or even more compact
print("The Sum:", int(input("Enter First Number:")) + int(input("Enter Second Number:")))
Output:
Enter First Number: 100 Enter Second Number: 200 The Sum: 300

Multiple Values (split)

Read multiple values from a single line using split() and list comprehension.

a, b = [int(x) for x in input("Enter 2 numbers :").split()]
print("Product is :", a * b)

# Sample run
# Enter 2 numbers :10 20
# Product is : 200
Output:
Enter 2 numbers : 10 20 Product is : 200
Tip
split() uses whitespace as the default separator, but you can pass any separator.

Comma-Separated Input

Read 3 float numbers separated by commas and calculate their sum.

a, b, c = [float(x) for x in input("Enter 3 float numbers :").split(',')]
print("The Sum is :", a + b + c)

# Sample run
# Enter 3 float numbers :10.5,20.6,20.1
# The Sum is : 51.2
Output:
Enter 3 float numbers : 10.5,20.6,20.1 The Sum is : 51.2

eval() Function

Evaluate Python expressions dynamically using eval().

# examples
x = eval("10+20+30")
print(x) # => 60

# evaluate an expression entered by the user
x = eval(input("Enter Expression"))
# Enter Expression: 10+2*3/4
# Output: 11.5

# eval() can also evaluate lists, tuples, etc.
l = eval(input("Enter List"))
print(type(l))
Output:
60 Enter Expression: 10+2*3/4 11.5
Security Warning
eval() executes arbitrary code and can be dangerous with untrusted input. Use safer alternatives like json.loads() or validate input before using eval().
