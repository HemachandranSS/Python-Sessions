Set Data Structure Overview

Sets are used to represent a group of unique values as a single entity. They're perfect for situations where you need to ensure uniqueness and perform mathematical set operations.

Key Characteristics of Sets

No Duplicates

Duplicate values are automatically removed. If you try to add the same element twice, it will only appear once in the set.

Unordered Collection

Elements don't have a fixed position. The order in which you add elements is not preserved, though you can sort them if needed.

No Indexing/Slicing

You cannot access set elements using indices like s[0] or slices like s[1:3]. Sets are not subscriptable.

Mutable & Dynamic

Sets are mutable - you can add or remove elements after creation. They can grow or shrink as needed.

Heterogeneous Elements

A set can contain different types of elements: integers, strings, tuples (immutable types). Lists and dictionaries cannot be set elements.

Mathematical Operations

Sets support mathematical operations like union, intersection, difference, and symmetric difference.

Creating Set Objects

Basic Set Creation

# Creating a set with curly braces s = {10, 20, 30, 40} print(s) # Output: {40, 10, 20, 30} (order may vary) print(type(s)) # Output: <class 'set'>

Creating Sets from Sequences

# Creating a set from a list (removes duplicates) l = [10, 20, 30, 40, 10, 20, 10] s = set(l) print(s) # Output: {40, 10, 20, 30} # Creating a set from a range s = set(range(5)) print(s) # Output: {0, 1, 2, 3, 4}

⚠️ IMPORTANT: Creating Empty Sets
When creating an empty set, you MUST use set(). Using {} creates an empty dictionary instead!

# ❌ WRONG: This creates a dictionary, not a set! s = {} print(type(s)) # Output: <class 'dict'> # ✅ CORRECT: This creates an empty set s = set() print(s) # Output: set() print(type(s)) # Output: <class 'set'>

Important Set Methods

1. add(x) - Add Single Element

s = {10, 20, 30} s.add(40) print(s) # Output: {40, 10, 20, 30}

2. update(x, y, z) - Add Multiple Elements

s = {10, 20, 30} l = [40, 50, 60, 10] s.update(l, range(5)) print(s) # Output: {0, 1, 2, 3, 4, 40, 10, 50, 20, 60, 30}

What's the difference between add() and update()?

add() update()
Adds individual item to set Adds multiple items to set
Takes exactly one argument Takes any number of arguments
Argument is the element itself Arguments must be iterable objects
s.add(10) s.update([10,20], range(5))

3. copy() - Create a Shallow Copy

s = {10, 20, 30} s1 = s.copy() print(s1) # Output: {10, 20, 30}

4. pop() - Remove and Return Random Element

s = {40, 10, 30, 20} print(s) # Output: {40, 10, 20, 30} print(s.pop()) # Output: 40 (or any random element) print(s) # Output: {10, 20, 30}

5. remove(x) vs 6. discard(x)

remove(x)

Removes specified element. Raises KeyError if element is not found.

s = {40, 10, 30, 20} s.remove(30) # ✅ Element exists # s.remove(50) # ❌ KeyError: 50

discard(x)

Removes specified element. Does NOT raise error if element is not found.

s = {10, 20, 30} s.discard(10) # ✅ Element exists s.discard(50) # ✅ No error even though 50 doesn't exist

7. clear() - Remove All Elements

s = {10, 20, 30} print(s) # Output: {10, 20, 30} s.clear() print(s) # Output: set()

Mathematical Set Operations

Sets in Python support all standard mathematical set operations, making them perfect for tasks involving collections and their relationships.

1. union() - Combine Sets

x = {10, 20, 30, 40} y = {30, 40, 50, 60} # Method 1: Using union() method print(x.union(y)) # Output: {10, 20, 30, 40, 50, 60} # Method 2: Using | operator print(x | y) # Output: {10, 20, 30, 40, 50, 60}

2. intersection() - Common Elements

x = {10, 20, 30, 40} y = {30, 40, 50, 60} # Method 1: Using intersection() method print(x.intersection(y)) # Output: {40, 30} # Method 2: Using & operator print(x & y) # Output: {40, 30}

3. difference() - Elements in A but not in B

x = {10, 20, 30, 40} y = {30, 40, 50, 60} print(x.difference(y)) # Output: {10, 20} print(x - y) # Output: {10, 20} print(y - x) # Output: {50, 60}

4. symmetric_difference() - Elements in Either but Not Both

x = {10, 20, 30, 40} y = {30, 40, 50, 60} print(x.symmetric_difference(y)) # Output: {10, 50, 20, 60} print(x ^ y) # Output: {10, 50, 20, 60}

Membership Operators (in, not in)

s = set("hema") print(s) # Output: {'h', 'e', 'm', 'a'} print('h' in s) # Output: True print('z' in s) # Output: False

Set Comprehension

Set comprehensions provide a concise way to create sets by applying an expression to each item in an iterable, optionally with a filtering condition.

Basic Set Comprehension

# Create set of squares from 0 to 4 s = {x * x for x in range(5)} print(s) # Output: {0, 1, 4, 9, 16}

Set Comprehension with Condition

# Create set of powers of 2 for even numbers s = {2 ** x for x in range(2, 10, 2)} print(s) # Output: {16, 256, 64, 4} # Create set of even numbers from 0 to 10 evens = {x for x in range(11) if x % 2 == 0} print(evens) # Output: {0, 2, 4, 6, 8, 10}

⚠️ No Indexing or Slicing! Remember that sets don't support indexing or slicing operations. You'll get TypeError if you try.

s = {10, 20, 30, 40} # print(s[0]) # ❌ TypeError: 'set' object does not support indexing # print(s[1:3]) # ❌ TypeError: 'set' object is not subscriptable

Practical Set Examples

Example 1: Eliminate Duplicates from a List

Approach 1: Using Sets

I = eval(input("Enter List of values: ")) s = set(I) print(s)
Output:
Enter List of values: [10,20,30,10,20,40]
{40, 10, 20, 30}

Approach 2: Manual Method

I = eval(input("Enter List of values: ")) I1 = [] for x in I: if x not in I1: I1.append(x) print(I1)
Output:
Enter List of values: [10,20,30,10,20,40]
[10, 20, 30, 40]

Example 2: Find Vowels in a Word

w = input("Enter word to search for vowels: ") # Convert word to set (unique letters) s = set(w) vowels = {'a', 'e', 'i', 'o', 'u'} result = s.intersection(vowels) print("The different vowels present in", w, "are", result)
Output:
Enter word to search for vowels: hema
The different vowels present in hema are {'e', 'a'}
