Introduction to Functions

If a group of statements is repeatedly required then it is not recommended to write these statements everytime separately. We have to define these statements as a single unit and we can call that unit any number of times based on our requirement without rewriting. This unit is nothing but function.

The main advantage of functions is code Reusability.

Note: In other languages functions are known as methods, procedures, subroutines etc.

Types of Functions

Python supports 2 types of functions:

1) Built-in Functions

The functions which are coming along with Python software automatically, are called built in functions or pre defined functions.

Examples: id(), type(), input(), eval(), etc.

2) User Defined Functions

The functions which are developed by programmer explicitly according to business requirements, are called user defined functions.

Function Syntax

Syntax to Create User defined Functions:

def function_name(parameters):
    """ doc string"""
    # function body
    return value

Note: While creating functions we can use 2 keywords:

  1. def (mandatory)
  2. return (optional)

Example 1: Write a function to print Hello

def wish():
    print("Hello Good Morning")

wish()
wish()
wish()

Example 2: Function with parameters

def wish(name):
    print("Hello", name, "Good Morning")

wish("Hema")   
wish("Ravi")
Output:
Hello Hema Good Morning
Hello Ravi Good Morning

Return Statement

Function can take input values as parameters and executes business logic, and returns output to the caller with return statement.

Q) Write a Function to accept 2 Numbers as Input and return Sum

def add(x, y):
    return x + y

result = add(10, 20)
print("The sum is", result)
print("The sum is", add(100, 200))

Note: If we are not writing return statement then default return value is None.

Returning Multiple Values from a Function:

In other languages like C, C++ and Java, function can return atmost one value. But in Python, a function can return any number of values.

def sum_sub(a, b):
    sum = a + b
    sub = a - b
    return sum, sub

x, y = sum_sub(100, 50)
print("The Sum is :", x)
print("The Subtraction is :", y)

Types of Arguments

There are 4 types of actual arguments allowed in Python:

1) Positional Arguments

These are the arguments passed to function in correct positional order.

def sub(a, b):
    print(a - b)

sub(100, 200)   # -100
sub(200, 100)   # 100

2) Keyword Arguments

We can pass argument values by keyword i.e by parameter name.

def wish(name, msg):
    print("Hello", name, msg)

wish(name="Hema", msg="Good Morning")
wish(msg="Good Morning", name="Hema")

3) Default Arguments

Sometimes we can provide default values for our positional arguments.

def wish(name="Guest"):
    print("Hello", name, "Good Morning")

wish("Hema")
wish()   # Uses default value

4) Variable Length Arguments

We can pass variable number of arguments to our function using * symbol.

def sum(*n):
    total = 0
    for n1 in n:
        total = total + n1
    print("The Sum=", total)

sum()
sum(10)
sum(10, 20)
sum(10, 20, 30, 40)

Recursive Functions

A function that calls itself is known as Recursive Function.

Example: Factorial using Recursion

factorial(3) = 3 * factorial(2)
= 3 * 2 * factorial(1)
= 3 * 2 * 1 * factorial(0)
= 3 * 2 * 1 * 1
= 6

factorial(n) = n * factorial(n-1)

def factorial(n):
    if n == 0:
        result = 1
    else:
        result = n * factorial(n - 1)
    return result

print("Factorial of 4 is :", factorial(4))
print("Factorial of 5 is :", factorial(5))

The main advantages of recursive functions are:

  1. We can reduce length of the code and improves readability.
  2. We can solve complex problems very easily.

Lambda Functions (Anonymous Functions)

Sometimes we can declare a function without any name, such type of nameless functions are called anonymous functions or lambda functions. The main purpose is for instant use (one time usage).

Syntax of Lambda Function: lambda argument_list : expression

Normal Function vs Lambda Function:

# Normal Function
def squareIt(n):
    return n * n

# Lambda Function
square = lambda n: n * n

Q) Lambda Function to find Square of given Number:

s = lambda n: n * n
print("The Square of 4 is :", s(4))
print("The Square of 5 is :", s(5))

Q) Lambda Function to find Biggest of given Values:

s = lambda a, b: a if a > b else b
print("The Biggest of 10,20 is:", s(10, 20))
print("The Biggest of 100,200 is:", s(100, 200))

Higher-Order Functions

filter() Function

We can use filter() function to filter values from the given sequence based on some condition.

# Filter even numbers using lambda
l = [0, 5, 10, 15, 20, 25, 30]
l1 = list(filter(lambda x: x % 2 == 0, l))
print(l1)   # [0, 10, 20, 30]

map() Function

For every element present in the given sequence, apply some functionality and generate new element.

# Double each element using lambda
l = [1, 2, 3, 4, 5]
l1 = list(map(lambda x: 2 * x, l))
print(l1)   # [2, 4, 6, 8, 10]

reduce() Function

reduce() function reduces sequence of elements into a single element by applying the specified function.

from functools import *
l = [10, 20, 30, 40, 50]
result = reduce(lambda x, y: x + y, l)
print(result)   # 150

Variable Scope

Python supports 2 types of variables:

1) Global Variables

The variables which are declared outside of function are called global variables. These can be accessed in all functions.

a = 10   # global variable

def f1():
    print(a)

def f2():
    print(a)

f1()   # 10
f2()   # 10

2) Local Variables

The variables which are declared inside a function are called local variables. Available only within that function.

def f1():
    a = 10   # local variable
    print(a)   # valid

def f2():
    print(a)   # invalid - NameError

global Keyword: Used to declare global variable inside function or to modify global variable.

a = 10
def f1():
    global a
    a = 777
    print(a)   # 777

f1()
print(a)   # 777 (global value changed)

Advanced Concepts

Function Aliasing

For the existing function we can give another name (function aliasing).

def wish(name):
    print("Good Morning:", name)

greeting = wish   # Function aliasing
greeting("Hema")
wish("Hema")

Nested Functions

We can declare a function inside another function (nested functions).

def outer():
    print("outer function started")
    
    def inner():
        print("inner function execution")
    
    inner()

outer()

Function Returning Another Function

def outer():
    print("outer function started")
    
    def inner():
        print("inner function execution")
    
    return inner

f1 = outer()   # f1 now references inner function
f1()   # Calls inner function
