Instance Methods, Class Methods & Static Methods Explained

Types of Methods in Python Classes

Instance Instance Methods

Methods that use instance variables. They require self as the first parameter.

  • Use instance variables (accessed via self)
  • Called using object reference
  • Most common type of method

Class Class Methods

Methods that use class/static variables. They require cls as the first parameter.

  • Use class/static variables
  • Declared with @classmethod decorator
  • Called using class name or object reference

Static Static Methods

General utility methods that don't use instance or class variables.

  • Don't use self or cls
  • Declared with @staticmethod decorator
  • General utility functions

Instance Methods

Basic Instance Method Example

Instance methods use self to access instance variables.

class Student:
  def __init__(self, name, marks):
    self.name = name
    self.marks = marks

  def display(self): # Instance method
    print('Hi', self.name)
    print('Your Marks are:', self.marks)

  def grade(self): # Instance method
    if self.marks >= 60:
      print('You got First Grade')
    elif self.marks >= 50:
      print('You got Second Grade')
    elif self.marks >= 35:
      print('You got Third Grade')
    else:
      print('You are Failed')

# Creating and using objects
s1 = Student("Hema", 90)
s1.display() # Call instance method
s1.grade() # Call instance method
Setter and Getter Methods

Setter (mutator) and Getter (accessor) methods are used to set and get values of instance variables.

Setter Methods

Used to set values to instance variables.

# Syntax
def setVariable(self, variable):
  self.variable = variable

# Example
def setName(self, name):
  self.name = name

Getter Methods

Used to get values of instance variables.

# Syntax
def getVariable(self):
  return self.variable

# Example
def getName(self):
  return self.name

Complete Setter/Getter Example

class Student:
  def setName(self, name):
    self.name = name # Setter method

  def getName(self):
    return self.name # Getter method

  def setMarks(self, marks):
    self.marks = marks # Setter method

  def getMarks(self):
    return self.marks # Getter method

# Using setter and getter methods
s = Student()
s.setName("Hema")
s.setMarks(95)
print('Hi', s.getName())
print('Your Marks are:', s.getMarks())
Hi Hema
Your Marks are: 95

Class Methods

Basic Class Method Example

Class methods use cls parameter and the @classmethod decorator.

class Animal:
  legs = 4 # Class/static variable

  @classmethod
  def walk(cls, name):
    print('{} walks with {} legs...'.format(name, cls.legs))

# Calling class method
Animal.walk('Dog')
Animal.walk('Cat')
Dog walks with 4 legs...
Cat walks with 4 legs...

Tracking Objects with Class Method

Class methods are useful for operations related to the class itself, not individual objects.

class Test:
  count = 0 # Class variable to track objects

  def __init__(self):
    Test.count = Test.count + 1 # Increment count

  @classmethod
  def noOfObjects(cls):
    print('The number of objects created:', cls.count)

# Create objects and track count
t1 = Test()
t2 = Test()
Test.noOfObjects() # Should show 2

t3 = Test()
t4 = Test()
t5 = Test()
Test.noOfObjects() # Should show 5
The number of objects created: 2
The number of objects created: 5

Static Methods

Static Methods - General Utility

Static methods don't use self or cls. They're general utility functions.

class HemaMath:
  @staticmethod
  def add(x, y):
    print('The Sum:', x + y)

  @staticmethod
  def product(x, y):
    print('The Product:', x * y)

  @staticmethod
  def average(x, y):
    print('The Average:', (x + y) / 2)

# Using static methods
HemaMath.add(10, 20)
HemaMath.product(10, 20)
HemaMath.average(10, 20)
The Sum: 30
The Product: 200
The Average: 15.0

Passing Members Between Classes

We can pass objects of one class to methods of another class to access their members.

class Employee:
  def __init__(self, eno, ename, esal):
    self.eno = eno
    self.ename = ename
    self.esal = esal

  def display(self):
    print('Employee Number:', self.eno)
    print('Employee Name:', self.ename)
    print('Employee Salary:', self.esal)

class Test:
  def modify(emp): # Receives Employee object
    emp.esal = emp.esal + 10000 # Modify salary
    emp.display()

# Creating Employee object and passing to Test method
e = Employee(100, 'Hema', 10000)
Test.modify(e) # Pass object to another class method
Employee Number: 100
Employee Name: Hema
Employee Salary: 20000
Key Insight

In this example, the Test.modify() method receives an Employee object as a parameter and can access and modify its instance variables. This demonstrates how objects can be passed between classes.

Important Notes

1. In general, we use mostly instance and static methods. Inside static methods, we can access class-level variables using the class name.

2. Class methods are the most rarely used methods in Python.
