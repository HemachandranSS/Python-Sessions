Python Modules Tutorial

Complete Guide to Importing, Using, and Creating Modules

Introduction to Modules

A module in Python is a file containing Python definitions and statements. Every Python file (.py) acts as a module. Modules help in organizing code logically.

Example: hemamath.py module

x = 888 def add(a, b): print("The Sum:", a + b) def product(a, b): print("The Product:", a * b)

The hemamath module contains one variable (x) and two functions (add, product).

Using the module in another file: test.py

import hemamath print(hemamath.x) hemamath.add(10, 20) hemamath.product(10, 20)
Output: 888 The Sum: 30 The Product: 200

Importing Modules

Python provides multiple ways to import modules and their members:

Import Methods:

  1. import module
  2. import module1, module2, module3
  3. import module as alias
  4. from module import member
  5. from module import member1, member2, member3
  6. from module import member as alias
  7. from module import *

Module Aliasing:

import hemamath as hm print(hm.x) hm.add(10, 20) hm.product(10, 20)

Importing specific members:

from hemamath import x, add print(x) add(10, 20) # product(10, 20) # This would cause NameError

Member Aliasing:

from hemamath import x as number, add as addition print(number) addition(10, 20)

Important: When using aliases, you must use the alias name, not the original name.

Reloading Modules

By default, Python loads a module only once, even if imported multiple times.

Example showing single loading:

import module1 import module1 import module1 print("Module loaded only once")

This can be problematic if the module is updated externally. The solution is explicit reloading.

Explicit reloading:

import module1 import imp imp.reload(module1) imp.reload(module1) print("Module reloaded multiple times")

Alternative (Python 3.4+):

import module1 import importlib importlib.reload(module1)

The dir() Function

The dir() function lists all members of a module.

List current module members:

x = 10 y = 20 def sample(): print("Hello") print(dir())
['__annotations__', '__builtins__', '__cached__', '__doc__', '__file__', '__loader__', '__name__', '__package__', '__spec__', 'sample', 'x', 'y']

List specific module members:

import hemamath print(dir(hemamath))
['__builtins__', '__cached__', '__doc__', '__file__', '__loader__', '__name__', '__package__', '__spec__', 'add', 'product', 'x']

The __name__ Variable

Every Python module has a built-in attribute called __name__.

  • When a module is run as the main program: __name__ = "__main__"
  • When a module is imported by another module: __name__ = module_name

Example module1.py:

def check_execution(): if __name__ == '__main__': print("Executed as main program") else: print("Imported as module") check_execution()

Example test.py:

import module1 module1.check_execution()
Running module1.py directly: Executed as main program Running test.py: Imported as module

Random Module

The random module generates random numbers for various applications.

1. random() - Random float between 0 and 1

import random print("Random float:", random.random())

2. randint() - Random integer in range [a, b]

print("Random integer 1-10:", random.randint(1, 10))

3. uniform() - Random float in range [a, b)

print("Random float 1-10:", random.uniform(1, 10))

4. randrange() - Random from range

print("Random 0-9:", random.randrange(10)) print("Random 1-10:", random.randrange(1, 11)) print("Random odd 1-10:", random.randrange(1, 11, 2))

5. choice() - Random element from sequence

names = ["Sunny", "Bunny", "Chinny", "Vinny", "Pinny"] print("Random name:", random.choice(names))

Quick Reference:

  • random(): 0 ≤ x < 1
  • randint(a, b): a ≤ x ≤ b (inclusive)
  • uniform(a, b): a ≤ x < b
  • randrange(start, stop, step): Like range()
  • choice(seq): Random element from sequence
