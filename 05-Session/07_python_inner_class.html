Understanding Inner Classes

What are Inner Classes?

Inner classes (or nested classes) are classes declared inside another class. They are used when one class cannot exist without the other.

Key Concept

Without existing one type of object, if there is no chance of existing another type of object, then we should go for inner classes.

Important Relationship

Without existing outer class object there is no chance of existing inner class object.

Inner class objects are always associated with outer class objects.

Person with Dob Inner Class

Example showing a Person class with a Date of Birth (Dob) inner class.

class Person:
  def __init__(self):
    self.name = 'Hema' # Changed from 'durga' to 'Hema'
    self.db = self.Dob() # Create inner class object

  def display(self):
    print('Name:', self.name)

  class Dob:
    def __init__(self):
      self.dd = 10
      self.mm = 5
      self.yy = 1947

    def display(self):
      print('Dob = {}/{}/{}'.format(self.dd, self.mm, self.yy))

# Using the Person and Dob classes
p = Person()
p.display()
x = p.db # Get the inner class object
x.display()
Name: Hema
Dob = 10/5/1947
Code Explanation

1. The Person class creates a Dob inner class object in its constructor.

2. The inner class object is stored as self.db.

3. We can access the inner class object via the outer class object.

Human with Multiple Inner Classes

A class can contain multiple inner classes.

class Human:
  def __init__(self):
    self.name = 'Sunny'
    self.head = self.Head() # First inner class
    self.brain = self.Brain() # Second inner class

  def display(self):
    print("Hello..", self.name)

  class Head:
    def talk(self):
      print('Talking...')

  class Brain:
    def think(self):
      print('Thinking...')

# Using the Human class with multiple inner classes
h = Human()
h.display()
h.head.talk()
h.brain.think()
Hello.. Sunny
Talking...
Thinking...
Multiple Inner Classes

Inside a class, we can declare any number of inner classes. Each inner class can have its own methods and attributes.

Inner Class Method Call Syntax

Multiple ways to create inner class objects and call their methods:

Method 1: Step-by-step

o = Outer()
i = o.Inner()
i.m1()

Create outer object, then inner object, then call method.

Method 2: Chained creation

i = Outer().Inner()
i.m1()

Create outer and inner objects in one line, then call method.

Method 3: Single line

Outer().Inner().m1()

Create objects and call method in a single line.

Complete Syntax Example

When to Use Inner Classes

  • When one class cannot logically exist without another
  • To logically group classes that are only used in one place
  • To increase encapsulation (inner class can be made private)
  • When the inner class needs access to outer class private members

When to Avoid Inner Classes

  • When classes can exist independently
  • When inner class logic becomes too complex
  • When inner class needs to be reused elsewhere
  • When it makes code harder to read and maintain

Important Notes

  • Inner class object cannot exist without outer class object
  • Inner classes increase code organization
  • Can lead to deeper nesting if overused
