Python Variables Guide

Instance Variables, Static Variables & Local Variables Explained

Types of Variables in Python Classes

Instance Instance Variables

If the value of a variable varies from object to object, such variables are called instance variables.

  • For every object, a separate copy of instance variables will be created
  • Also known as object-level variables

Static Static Variables

If the value of a variable is not varied from object to object, such variables are called static variables.

  • For the total class, only one copy of static variable will be created
  • Shared by all objects of that class
  • Also known as class-level variables

Local Local Variables

Variables declared inside a method to meet temporary requirements are called local variables.

  • Created at the time of method execution
  • Destroyed once method completes
  • Also known as method-level variables

Instance Variables (Object-Level)

Where to Declare Instance Variables:

1. Inside Constructor using self

class Employee:
  def __init__(self):
    self.eno = 100
    self.ename = 'Hema'
    self.esal = 10000

e = Employee()
print(e.__dict__)
{'eno': 100, 'ename': 'Hema', 'esal': 10000}

2. Inside Instance Method using self

class Test:
  def __init__(self):
    self.a = 10
    self.b = 20

  def m1(self):
    self.c = 30

t = Test()
t.m1()
print(t.__dict__)
{'a': 10, 'b': 20, 'c': 30}

3. Outside Class using Object Reference

class Test:
  def __init__(self):
    self.a = 10
    self.b = 20

  def m1(self):
    self.c = 30

t = Test()
t.m1()
t.d = 40 # Outside class
print(t.__dict__)
{'a': 10, 'b': 20, 'c': 30, 'd': 40}

How to Access Instance Variables

Inside class: Using self
Outside class: Using object reference

class Test:
  def __init__(self):
    self.a = 10
    self.b = 20

  def display(self):
    print(self.a) # Access inside class
    print(self.b)

t = Test()
t.display() # Access via method
print(t.a, t.b) # Access outside class
10
20
10 20

Modifying and Deleting Instance Variables

class Test:
  def __init__(self):
    self.a = 10
    self.b = 20
    self.c = 30
    self.d = 40

  def m1(self):
    del self.d # Delete inside class

t = Test()
print(t.__dict__)
t.m1()
print(t.__dict__)
del t.c # Delete outside class
print(t.__dict__)
{'a': 10, 'b': 20, 'c': 30, 'd': 40}
{'a': 10, 'b': 20, 'c': 30}
{'a': 10, 'b': 20}
Important Note

Instance variables deleted from one object will not be deleted from other objects. Each object maintains its own copy.

Key Insight

Changing instance variables of one object does not affect other objects because each object has its own separate copy of instance variables.

Static Variables (Class-Level)

Static vs Instance Variables

Instance Variables Static Variables
Separate copy for each object One copy shared by all objects
Declared with self Declared directly in class (outside methods)
Accessed via object reference Accessed via class name (recommended)
Values vary per object Same value for all objects

Basic Static Variable Example

class Test:
  x = 10 # Static variable
  def __init__(self):
    self.y = 20 # Instance variable

t1 = Test()
t2 = Test()
print('t1:', t1.x, t1.y)
print('t2:', t2.x, t2.y)

Test.x = 888 # Modify static variable
t1.y = 999 # Modify instance variable
print('t1:', t1.x, t1.y)
print('t2:', t2.x, t2.y)
t1: 10 20
t2: 10 20
t1: 888 999
t2: 888 20

Where to Declare Static Variables

class Test:
  a = 10 # 1. Directly in class
  def __init__(self):
    Test.b = 20 # 2. In constructor
  def m1(self):
    Test.c = 30 # 3. In instance method
  @classmethod
  def m2(cls):
    cls.d1 = 40 # 4. In classmethod (cls)
    Test.d2 = 400 # 4. In classmethod (classname)
  @staticmethod
  def m3():
    Test.e = 50 # 5. In static method

# Checking all declarations
t = Test()
t.m1()
Test.m2()
Test.m3()
Test.f = 60 # 6. Outside class
print(Test.__dict__)

How to Access Static Variables

class Test:
  a = 10
  def __init__(self):
    print(self.a) # Constructor: self
    print(Test.a) # Constructor: classname
  def m1(self):
    print(self.a) # Instance method: self
    print(Test.a) # Instance method: classname
  @classmethod
  def m2(cls):
    print(cls.a) # Class method: cls
    print(Test.a) # Class method: classname
  @staticmethod
  def m3():
    print(Test.a) # Static method: classname

t = Test()
print(Test.a) # Outside: classname
print(t.a) # Outside: object reference
t.m1()
t.m2()
t.m3()
Important Warning

If you try to change a static variable using self or object reference, Python creates a new instance variable instead of modifying the static variable!

Local Variables (Method-Level)

Local Variable Basics

Local variables are temporary variables declared inside methods. They:

  • Are created when method executes
  • Are destroyed when method completes
  • Cannot be accessed from outside the method
class Test:
  def m1(self):
    a = 1000 # Local variable
    print(a)
  def m2(self):
    b = 2000 # Local variable
    print(b)

t = Test()
t.m1()
t.m2()
1000
2000

Local Variable Scope

Local variables are only accessible within the method where they're declared.

class Test:
  def m1(self):
    a = 1000
    print(a)
  def m2(self):
    b = 2000
    # print(a) # This would cause NameError!
    print(b)

t = Test()
t.m1()
t.m2()
1000
2000
Scope Limitation

If you uncomment print(a) in m2(), you'll get NameError: name 'a' is not defined because local variables have method-level scope only.

Complete Bank Program Example
import sys
class Customer:
  ''' Customer class with bank operations '''
  bankname = 'HEMABANK' # Static variable
  def __init__(self, name, balance = 0.0):
    self.name = name # Instance variable
    self.balance = balance # Instance variable
  def deposit(self, amt):
    self.balance = self.balance + amt
    print('Balance after deposit:', self.balance)
  def withdraw(self, amt):
    if amt > self.balance:
      print('Insufficient Funds..cannot perform this operation')
      sys.exit()
    self.balance = self.balance - amt
    print('Balance after withdraw:', self.balance)

print('Welcome to', Customer.bankname)
name = input('Enter Your Name: ')
c = Customer(name)
while True:
  print('d-Deposit \\nw-Withdraw \\ne-exit')
  option = input('Choose your option: ')
  if option == 'd' or option == 'D':
    amt = float(input('Enter amount: '))
    c.deposit(amt)
  elif option == 'w' or option == 'W':
    amt = float(input('Enter amount: '))
    c.withdraw(amt)
  elif option == 'e' or option == 'E':
    print('Thanks for Banking')
    sys.exit()
  else:
    print('Invalid option..Plz choose valid option')
