Python Decorator Functions

A Decorator is a function that takes another function as an argument, extends its functionality, and returns a modified function without changing the original function definition.

Basic Example: wish() Function

def wish(name):
    print("Hello", name, "Good Morning")

wish("Hema")
wish("Ravi")
wish("Sunny")
Hello Hema Good Morning Hello Ravi Good Morning Hello Sunny Good Morning

Suppose we want to change the behavior only when the name is Sunny, without modifying the wish() function. This can be achieved using a decorator.

Using Decorator

def decor(func):
    def inner(name):
        if name == "Sunny":
            print("Hello Sunny Bad Morning")
        else:
            func(name)
    return inner

@decor
def wish(name):
    print("Hello", name, "Good Morning")

wish("Hema")
wish("Ravi")
wish("Sunny")
Hello Hema Good Morning Hello Ravi Good Morning Hello Sunny Bad Morning

Calling Function With and Without Decorator

def decor(func):
    def inner(name):
        if name == "Sunny":
            print("Hello Sunny Bad Morning")
        else:
            func(name)
    return inner


def wish(name):
    print("Hello", name, "Good Morning")


decorfunction = decor(wish)

wish("Hema")      # decorator not executed
wish("Sunny")    # decorator not executed

decorfunction("Hema")   # decorator executed
decorfunction("Sunny")  # decorator executed
Hello Hema Good Morning Hello Sunny Good Morning Hello Hema Good Morning Hello Sunny Bad Morning

Smart Division Decorator

def smart_division(func):
    def inner(a, b):
        print("We are dividing", a, "with", b)
        if b == 0:
            print("OOPS... cannot divide")
            return
        return func(a, b)
    return inner

@smart_division
def division(a, b):
    return a / b

print(division(20, 2))
print(division(20, 0))
We are dividing 20 with 2 10.0 We are dividing 20 with 0 OOPS... cannot divide None

Marriage Decoration Example

def marriagedecor(func):
    def inner():
        print('Hair decoration...')
        print('Face decoration with Platinum package')
        print('Fair and Lovely etc..')
        func()
    return inner


def getready():
    print('Ready for the marriage')


decorated_getready = marriagedecor(getready)
decorated_getready()
Hair decoration... Face decoration with Platinum package Fair and Lovely etc.. Ready for the marriage

Decorator Chaining

Applying multiple decorators to the same function is called Decorator Chaining. The decorator closest to the function executes first. 

def decor1(func):
    def inner():
        x = func()
        return x * x
    return inner


def decor(func):
    def inner():
        x = func()
        return 2 * x
    return inner

@decor1
@decor
def num():
    return 10

print(num())
400
