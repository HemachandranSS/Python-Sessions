What are Abstract Methods?

Abstract methods are methods that are declared but contain no implementation. They serve as a blueprint for methods that must be implemented in child classes. In Python, we declare abstract methods using the @abstractmethod decorator from the abc module.

1. Abstract Methods and Abstract Classes

Declaring Abstract Methods

Note: The @abstractmethod decorator is present in the abc (Abstract Base Class) module. You must import it, otherwise you'll get an error.
Import Error Example 
class Test:
    @abstractmethod
    def m1(self):
        pass

# NameError: name 'abstractmethod' is not defined
Correct Way to Declare Abstract Method 
from abc import ABC, abstractmethod

class Fruit:
    @abstractmethod
    def taste(self):
        pass
Important: Child classes are responsible for providing implementation for parent class abstract methods.

Abstract Classes - Different Cases

Case 1: Concrete Class (Can Create Object)
from abc import ABC, abstractmethod

class Test:
    pass

t = Test()  # Valid: No abstract methods
Case 2: ABC Class Without Abstract Methods (Can Create Object)
from abc import ABC, abstractmethod

class Test(ABC):
    pass

t = Test()  # Valid: Even though it extends ABC, no abstract methods
Case 3: ABC Class With Abstract Method (Cannot Create Object)
from abc import ABC, abstractmethod

class Test(ABC):
    @abstractmethod
    def m1(self):
        pass

t = Test()  # TypeError: Can't instantiate abstract class Test with abstract methods m1
Case 4: Class With Abstract Method But Not Extending ABC (Can Create Object)
from abc import abstractmethod

class Test:
    @abstractmethod
    def m1(self):
        pass

t = Test()  # Valid: Not extending ABC class
Case 5: Abstract Method With Implementation (Rare Case)
from abc import abstractmethod

class Test:
    @abstractmethod
    def m1(self):
        print('Hello')

t = Test()
t.m1()  # Output: Hello
Conclusion: If a class contains at least one abstract method and extends the ABC class, instantiation is NOT possible. "Abstract class with abstract method instantiation is not possible."

Implementing Abstract Methods in Child Classes

Vehicle Abstract Class Example 
from abc import ABC, abstractmethod

class Vehicle(ABC):
    @abstractmethod
    def noofwheels(self):
        pass

class Bus(Vehicle):
    def noofwheels(self):
        return 7

class Auto(Vehicle):
    def noofwheels(self):
        return 3

b = Bus()
print(b.noofwheels())  # Output: 7

a = Auto()
print(a.noofwheels())  # Output: 3

Output:

7 3
Note: Abstract classes can contain both abstract and non-abstract (concrete) methods.

2. Interfaces in Python

In general, if an abstract class contains only abstract methods, such a type of abstract class is considered as an interface.

Database Interface Example 
from abc import ABC, abstractmethod

class DBInterface(ABC):
    @abstractmethod
    def connect(self):
        pass
    
    @abstractmethod
    def disconnect(self):
        pass

class Oracle(DBInterface):
    def connect(self):
        print("Connecting to Oracle Database...")
    
    def disconnect(self):
        print("Disconnecting from Oracle Database...")

class Sybase(DBInterface):
    def connect(self):
        print("Connecting to Sybase Database...")
    
    def disconnect(self):
        print("Disconnecting from Sybase Database...")

# Dynamic class instantiation based on user input
dbname = input('Enter Database Name: ')
classname = globals()[dbname]
x = classname()
x.connect()
x.disconnect()
Sample Output 1:
Enter Database Name: Oracle
Connecting to Oracle Database...
Disconnecting from Oracle Database...

Sample Output 2:
Enter Database Name: Sybase
Connecting to Sybase Database...
Disconnecting from Sybase Database...
Note: The built-in function globals()[str] converts the string 'str' into a class name and returns the class.

Reading Class Name from File

Printer Interface Example 
from abc import ABC, abstractmethod

class Printer(ABC):
    @abstractmethod
    def printit(self, text):
        pass
    
    @abstractmethod
    def disconnect(self):
        pass

class EPSON(Printer):
    def printit(self, text):
        print('Printing from EPSON Printer...')
        print(text)
    
    def disconnect(self):
        print('Printing completed on EPSON Printer...')

class HP(Printer):
    def printit(self, text):
        print('Printing from HP Printer...')
        print(text)
    
    def disconnect(self):
        print('Printing completed on HP Printer...')

# Read printer name from config file
with open('config.txt', 'r') as f:
    pname = f.readline().strip()

classname = globals()[pname]
x = classname()
x.printit('This data has to print...')
x.disconnect()

Output (if config.txt contains "EPSON"):

Printing from EPSON Printer... This data has to print... Printing completed on EPSON Printer...

3. Concrete Class vs Abstract Class vs Interface

Type When to Use Example
Interface When you don't know about implementation, just have requirement specifications Only abstract methods, no implementation
Abstract Class When you know about implementation but not completely (partially implemented) Mix of abstract and concrete methods
Concrete Class When you know implementation completely and ready to provide service All methods have complete implementation
Complete Example 
from abc import ABC, abstractmethod

class CollegeAutomation(ABC):
    @abstractmethod
    def m1(self):
        pass
    
    @abstractmethod
    def m2(self):
        pass
    
    @abstractmethod
    def m3(self):
        pass

class AbsCls(CollegeAutomation):
    def m1(self):
        print('m1 method implementation')
    
    def m2(self):
        print('m2 method implementation')

class ConcreteCls(AbsCls):
    def m3(self):
        print('m3 method implementation')

c = ConcreteCls()
c.m1()
c.m2()
c.m3()

Output:

m1 method implementation m2 method implementation m3 method implementation

4. Public, Protected and Private Attributes

Public Attributes

Default in Python. Accessible from anywhere - within the class or from outside.

name = 'Hema'

Protected Attributes

Accessible within the class and in child classes. Convention only, prefixed with _.

_name = 'Hema'

Private Attributes

Accessible only within the class. Prefixed with __ (double underscore).

__name = 'Hema'
Access Modifiers Example 
class Test:
    x = 10           # Public
    _y = 20          # Protected
    __z = 30         # Private
    
    def m1(self):
        print(Test.x)     # Accessible
        print(Test._y)    # Accessible
        print(Test.__z)   # Accessible (inside class)

t = Test()
t.m1()
print(Test.x)       # Accessible
print(Test._y)      # Accessible (but convention says don't)
# print(Test.__z)   # AttributeError: type object 'Test' has no attribute '__z'

Output:

10 20 30 10 20
Note: Protected attributes (_name) are just a convention in Python. They can still be accessed from outside, but it's considered bad practice.

Accessing Private Variables Indirectly

Access Private Variables 
class Test:
    def __init__(self):
        self.__x = 10

t = Test()
# Direct access won't work
# print(t.__x)  # AttributeError

# Indirect access using name mangling
print(t._Test__x)  # Output: 10

5. __str__() Method

The __str__() method is called when we print any object. By default, it returns a string in the format: <__main__.ClassName object at 0xmemoryaddress>. We can override this method to return meaningful string representation.

Overriding __str__() Method 
class Student:
    def __init__(self, name, rollno):
        self.name = name
        self.rollno = rollno
    
    def __str__(self):
        return f'Student Name: {self.name}, Roll No: {self.rollno}'

s1 = Student('Hema', 101)
s2 = Student('Ravi', 102)
print(s1)
print(s2)

Output:

Student Name: Hema, Roll No: 101 Student Name: Ravi, Roll No: 102
Without overriding __str__(): Output would be: <__main__.Student object at 0x022144B0>

6. Difference between str() and repr()

Function Purpose Key Difference
str() Returns a nicely printable string representation For readability. May not convert back to original object.
repr() Returns an unambiguous string representation For debugging. Can convert back using eval().
str() Example - Cannot Convert Back 
import datetime

today = datetime.datetime.now()
s = str(today)  # Convert datetime to string
print(s)

# Try to convert back (will fail)
# d = eval(s)  # SyntaxError: invalid token
repr() Example - Can Convert Back 
import datetime

today = datetime.datetime.now()
s = repr(today)  # Convert datetime to repr string
print(s)

# Convert back using eval()
d = eval(s)
print(d)

Output:

datetime.datetime(2023, 12, 19, 14, 30, 25, 123456) 2023-12-19 14:30:25.123456
Recommendation: It's generally better to use repr() instead of str() for debugging purposes, as it provides unambiguous representation.

7. Mini Project: Banking Application

Complete Banking Application 
class Account:
    def __init__(self, name, balance, min_balance):
        self.name = name
        self.balance = balance
        self.min_balance = min_balance
    
    def deposit(self, amount):
        self.balance += amount
    
    def withdraw(self, amount):
        if self.balance - amount >= self.min_balance:
            self.balance -= amount
        else:
            print("Sorry, Insufficient Funds")
    
    def printStatement(self):
        print(f"Account Balance: {self.balance}")

class Current(Account):
    def __init__(self, name, balance):
        super().__init__(name, balance, min_balance=-1000)
    
    def __str__(self):
        return f"{self.name}'s Current Account with Balance: {self.balance}"

class Savings(Account):
    def __init__(self, name, balance):
        super().__init__(name, balance, min_balance=0)
    
    def __str__(self):
        return f"{self.name}'s Savings Account with Balance: {self.balance}"

# Test the banking application
c = Savings("Hema", 10000)
print(c)
c.deposit(5000)
c.printStatement()
c.withdraw(16000)  # Should show insufficient funds
c.withdraw(15000)
print(c)

c2 = Current('Ravi', 20000)
c2.deposit(6000)
print(c2)
c2.withdraw(27000)
print(c2)

Output:

Hema's Savings Account with Balance: 10000 Account Balance: 15000 Sorry, Insufficient Funds Hema's Savings Account with Balance: 0 Ravi's Current Account with Balance: 26000 Ravi's Current Account with Balance: -1000
Features Demonstrated:
  • Inheritance (Savings and Current extend Account)
  • Method Overriding (__str__() method)
  • super() method usage
  • Encapsulation with private attributes
  • Polymorphism with different account types
