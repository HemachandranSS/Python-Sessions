Python File I/O Complete Tutorial

Introduction to Files

As part of programming requirements, we need to store our data permanently for future purposes. For this requirement, we should use files.

Files are very common permanent storage areas to store our data.

Types of Files

File Type Description Example
Text Files Used to store character data abc.txt
Binary Files Used to store binary data like images, video files, audio files image.jpg, video.mp4, audio.mp3

Opening a File

Before performing any operation (like read or write) on a file, we must first open that file. Python provides an inbuilt function open() for this purpose.

f = open(filename, mode)

File Opening Modes

Mode Description
r Open for reading (default). File pointer at beginning. FileNotFoundError if file doesn't exist.
w Open for writing. Overrides existing data. Creates file if it doesn't exist.
a Open for appending. Doesn't override existing data. Creates file if it doesn't exist.
r+ Read and write. Doesn't delete previous data. Pointer at beginning.
w+ Write and read. Overrides existing data.
a+ Append and read. Doesn't override existing data.
x Exclusive creation mode for write. FileExistsError if file exists.
Note: All the above modes are for text files. If these modes are suffixed with 'b', they represent binary files.
Examples: rb, wb, ab, r+b, w+b, a+b, xb

Example:

f = open("abc.txt", "w")
# We are opening abc.txt file for writing data

Closing a File

After completing operations on a file, it is highly recommended to close the file using the close() function.

f.close()

File Object Properties

Once we open a file and get a file object, we can retrieve various details about that file using its properties:

  • name - Name of the opened file
  • mode - Mode in which the file is opened
  • closed - Returns boolean indicating if file is closed
  • readable() - Returns boolean indicating if file is readable
  • writable() - Returns boolean indicating if file is writable

Example:

f = open("abc.txt", 'w')
print("File Name: ", f.name)
print("File Mode: ", f.mode)
print("Is File Readable: ", f.readable())
print("Is File Writable: ", f.writable())
print("Is File Closed: ", f.closed)
f.close()
print("Is File Closed: ", f.closed)
File Name: abc.txt
File Mode: w
Is File Readable: False
Is File Writable: True
Is File Closed: False
Is File Closed: True

Writing Data to Text Files

We can write character data to text files using the following methods:

  • write(str) - Write a string to the file
  • writelines(list) - Write a list of strings to the file

Example 1: Using write()

f = open("abcd.txt", 'w')
f.write("Hema\n")
f.write("Software\n")
f.write("Solutions\n")
print("Data written to the file successfully")
f.close()
abcd.txt contents:
Hema
Software
Solutions
Note: In the above program, data in the file will be overridden every time we run the program. For append operation, open the file with mode "a": 
f = open("abcd.txt", "a")

Example 2: Using writelines()

f = open("abcd.txt", 'w')
list = ["sunny\n", "bunny\n", "vinny\n", "chinny"]
f.writelines(list)
print("List of lines written to the file successfully")
f.close()
abcd.txt contents:
sunny
bunny
vinny
chinny
Note: When writing data using write() methods, you must provide line separator (\n), otherwise all data will be written to a single line.

Reading Data from Text Files

We can read character data from text files using these methods:

  • read() - Read total data from the file
  • read(n) - Read 'n' characters from the file
  • readline() - Read only one line
  • readlines() - Read all lines into a list

Example 1: Read Total Data

f = open("abc.txt", 'r')
data = f.read()
print(data)
f.close()

The with Statement

The with statement can be used when opening files. It groups file operation statements within a block.

Advantage: The with statement automatically takes care of closing the file after completing all operations, even in case of exceptions. We don't need to close explicitly. 
with open("abc.txt", "w") as f:
    f.write("Hema\n")
    f.write("Software\n")
    f.write("Solutions\n")
    print("Is File Closed: ", f.closed)
print("Is File Closed: ", f.closed)
Is File Closed: False
Is File Closed: True

The seek() and tell() Methods

tell() Method

The tell() method returns the current position of the cursor (file pointer) from the beginning of the file. The position (index) of the first character is zero, just like string indexing.

f = open("abc.txt", "r")
print(f.tell())
print(f.read(2))
print(f.tell())
print(f.read(3))
print(f.tell())
0
su
2
nny
5

seek() Method

The seek() method moves the cursor (file pointer) to a specified location.

f.seek(offset, fromwhere)

Allowed values for 'fromwhere':

  • 0 - From beginning of file (default)
  • 1 - From current position
  • 2 - From end of file
Note: Python 2 supports all 3 values, but Python 3 supports only zero. 
data = "All Students are STUPIDS"
f = open("abc.txt", "w")
f.write(data)
with open("abc.txt", "r+") as f:
    text = f.read()
    print(text)
    print("The Current Cursor Position: ", f.tell())
    f.seek(17)
    print("The Current Cursor Position: ", f.tell())
    f.write("GEMS!!!")
    f.seek(0)
    text = f.read()
    print("Data After Modification:")
    print(text)
All Students are STUPIDS
The Current Cursor Position: 24
The Current Cursor Position: 17
Data After Modification:
All Students are GEMS!!!

Checking File Existence

We can use the os library to get information about files. The os module has a path sub-module containing the isfile() function to check whether a file exists.

os.path.isfile(fname)

Example: Check File Existence and Print Content

import os, sys
fname = input("Enter File Name: ")
if os.path.isfile(fname):
    print("File exists:", fname)
    f = open(fname, "r")
else:
    print("File does not exist:", fname)
    sys.exit(0)
print("The content of file is:")
data = f.read()
print(data)
Enter File Name: hema.txt
File does not exist: hema.txt

Enter File Name: abc.txt
File exists: abc.txt
The content of file is:
All Students are GEMS!!!
Note: sys.exit(0) exits the system without executing the rest of the program. The argument represents status code (0 means normal termination).

Counting Lines, Words, and Characters

Program to print the number of lines, words, and characters in a file:

import os, sys
fname = input("Enter File Name: ")
if os.path.isfile(fname):
    print("File exists:", fname)
    f = open(fname, "r")
else:
    print("File does not exist:", fname)
    sys.exit(0)

lcount = wcount = ccount = 0
for line in f:
    lcount = lcount + 1
    ccount = ccount + len(line)
    words = line.split()
    wcount = wcount + len(words)

print("The number of Lines:", lcount)
print("The number of Words:", wcount)
print("The number of Characters:", ccount)

File exists: abc.txt
The number of Lines: 6
The number of Words: 24
The number of Characters: 149

Handling CSV Files

CSV stands for Comma Separated Values. Python provides the csv module to handle CSV files.

Writing Data to CSV File

import csv
with open("emp.csv", "w", newline='') as f:
    w = csv.writer(f)  # returns csv writer object
    w.writerow(["ENO", "ENAME", "ESAL", "EADDR"])
    n = int(input("Enter Number of Employees:"))
    for i in range(n):
        eno = input("Enter Employee No:")
        ename = input("Enter Employee Name:")
        esal = input("Enter Employee Salary:")
        eaddr = input("Enter Employee Address:")
        w.writerow([eno, ename, esal, eaddr])
print("Total Employees data written to csv file successfully")
Note: The newline attribute prevents blank lines between data rows in Python 3. In Python 2, use mode 'wb' instead.

Reading Data from CSV File

import csv
f = open("emp.csv", 'r')
r = csv.reader(f)  # returns csv reader object
data = list(r)
for line in data:
    for word in line:
        print(word, "\t", end='')
    print()

Zipping and Unzipping Files

Python's zipfile module provides functionality to zip and unzip files.

Main Advantages:

  • Improve memory utilization
  • Reduce transport time
  • Improve performance

Creating a Zip File

from zipfile import *
f = ZipFile("files.zip", 'w', ZIP_DEFLATED)
f.write("file1.txt")
f.write("file2.txt")
f.write("file3.txt")
f.close()
print("files.zip file created successfully")
Note: ZIP_DEFLATED constant represents creating a zip file.

Unzipping Files

from zipfile import *
f = ZipFile("files.zip", 'r', ZIP_STORED)
names = f.namelist()
for name in names:
    print("File Name: ", name)
    print("The Content of this file is:")
    f1 = open(name, 'r')
    print(f1.read())
    print()
Note: ZIP_STORED represents unzip operation (default value).

Working with Directories

Python provides the os module to perform directory-related operations:

Common Directory Operations

1. Get Current Working Directory

import os
cwd = os.getcwd()
print("Current Working Directory:", cwd)

2. Create a Sub Directory

import os
os.mkdir("mysub")
print("mysub directory created in cwd")

3. Create Nested Directories

import os
os.mkdir("mysub/mysub2")
print("mysub2 created inside mysub")

4. Create Multiple Directory Levels

import os
os.makedirs("sub1/sub2/sub3")
print("sub1, sub2, and sub3 directories created")

5. Remove a Directory

import os
os.rmdir("mysub/mysub2")
print("mysub2 directory deleted")

6. Remove Multiple Directories

import os
os.removedirs("sub1/sub2/sub3")
print("All 3 directories removed")

7. Rename a Directory

import os
os.rename("mysub", "newdir")
print("mysub directory renamed to newdir")

8. List Directory Contents

import os
print(os.listdir("."))
Note: listdir() shows contents of the specified directory but not subdirectories.

9. List Contents Including Subdirectories (walk())

import os
for dirpath, dirnames, filenames in os.walk('.'):
    print("Current Directory Path:", dirpath)
    print("Directories:", dirnames)
    print("Files:", filenames)
    print()
walk() parameters:
  • path - Directory path (. for current)
  • topdown - True: traverse top to bottom
  • onerror - Function to execute on error
  • followlinks - True: visit symbolic link directories

Getting File Information

We can get file statistics like size, access time, and modification time using the stat() function.

stats = os.stat("abc.txt")

File Statistics Parameters

Parameter Description
st_mode Protection bits
st_ino Inode number
st_dev Device
st_nlink Number of hard links
st_uid User ID of owner
st_gid Group ID of owner
st_size Size of file in bytes
st_atime Time of most recent access
st_mtime Time of most recent modification
st_ctime Time of most recent metadata change

Example: Print File Statistics

import os
stats = os.stat("abc.txt")
print(stats)

Example: Print Specific Properties

import os
from datetime import *
stats = os.stat("abc.txt")
print("File Size in Bytes:", stats.st_size)
print("File Last Accessed Time:", datetime.fromtimestamp(stats.st_atime))
print("File Last Modified Time:", datetime.fromtimestamp(stats.st_mtime))

Pickling and Unpickling Objects

Object (e1)
→
pickle.dump()
→
File (abc.txt)
→

Object (e2)

Sometimes we need to write the complete state of an object to a file and read it back.

  • Pickling - Writing object state to file
  • Unpickling - Reading object state from file

Python's pickle module provides these functions:

  • pickle.dump(object, file) - For pickling
  • pickle.load(file) - For unpickling

Example: Pickle and Unpickle an Employee Object

import pickle

class Employee:
    def __init__(self, eno, ename, esal, eaddr):
        self.eno = eno
        self.ename = ename
        self.esal = esal
        self.eaddr = eaddr
    
    def display(self):
        print(self.eno, "\t", self.ename, "\t", self.esal, "\t", self.eaddr)

with open("emp.dat", "wb") as f:
    e = Employee(100, "Hema", 1000, "Hyd")
    pickle.dump(e, f)
    print("Pickling of Employee Object completed...")

with open("emp.dat", "rb") as f:
    obj = pickle.load(f)
    print("Printing Employee Information after unpickling")
    obj.display()

Writing Multiple Employee Objects

emp.py:

class Employee:

        self.eno = eno

        self.esal = esal

pick.py:

import emp, pickle
f = open("emp.dat", "wb")
n = int(input("Enter The number of Employees:"))
for i in range(n):
    eno = int(input("Enter Employee Number:"))
    ename = input("Enter Employee Name:")
    esal = float(input("Enter Employee Salary:"))
    eaddr = input("Enter Employee Address:")
    e = emp.Employee(eno, ename, esal, eaddr)
    pickle.dump(e, f)
print("Employee Objects pickled successfully")

unpick.py:

import emp, pickle
f = open("emp.dat", "rb")
print("Employee Details:")
while True:
    try:
        obj = pickle.load(f)
        obj.display()
    except EOFError:
        print("All employees Completed")
        break
f.close()
